## v1.16.86 修复撤离弹层按钮失效
- 真因：render.js evacuationLayer 写成 hits.evacGo = button(...).hit（存的是裸命中函数），而 dispatchTouch 按 H.evacGo.hit(p) 调用 → 函数对象上无 .hit → 永不命中且 return true 吞点击。
- 修复：改为 hits.evacGo = button(...) 直接存 {hit} 对象（与 gameover 弹层 restart.hit 取法一致的约定：push 进 hits 的应是 {hit} 对象）。
- 新增 tools/_test_evacuation.mjs：mock wx 启动整局，渲染一帧填充 evacHits，模拟 touchstart 点击两按钮，断言 继续→startNextWave/state=fighting、撤离→finishRun/state=gameover。PASS。
- 已上传 v1.16.86（3.5MB）。
