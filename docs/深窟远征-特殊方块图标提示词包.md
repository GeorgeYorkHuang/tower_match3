## 2. 色板（36 张共用，逐色替换）

每档颜色给 5 个值：玻璃亮面、玻璃暗面、内缘亮线、符号色、光晕色。
**符号一律用近白偏色**，保证同色块上形状仍靠亮度差跳出来（56px 不靠色相辨形）。

| 色 | 亮面 | 暗面 | 内缘亮线 | 符号 | 光晕 |
|---|---|---|---|---|---|
| red | `#ff8a8a` | `#e04a55` | `#ffd6d6` | `#fff5f5` | `#ff6b6b` |
| blue | `#7fd0f5` | `#2f86bf` | `#d6f2ff` | `#f4fdff` | `#5dade2` |
| green | `#7ce8a8` | `#2f9e63` | `#d3ffe4` | `#f3fff8` | `#58d68d` |
| yellow | `#ffe680` | `#d9a91a` | `#fffbd0` | `#fffdf0` | `#f4d03f` |
| purple | `#d4a8e8` | `#8b55b0` | `#f2e2fb` | `#fdf5ff` | `#af7ac5` |
| orange | `#ffb066` | `#c25f10` | `#ffe0bd` | `#fff7ee` | `#e67e22` |

边缘处理：**无深色描边**——用「内缘亮线 + 微弱同色深边」收口，与普通方块（半透明冰晶、边缘泛白光）一致。
tile 主体半透明：生成时明确 `translucent / frosted / semi-transparent`，避免画成实心塑料。

**子雷例外**：不随来源色变化——恒为红警配色（底 `#3a080e`、线 `#ff9aa5` / `#ff4d5e`），
仅符号层的菱形与臂尖保留，用于一眼区分「这是子雷，别和十字爆混」。

## 3. Prompt 骨架

36 条 = **A（带色玻璃体，逐色替换）+ B（形状，逐款固定）+ C（负面，逐字复用）**。

### A 段（把 `{...}` 换成色板值）

> **v2.1 修正**：首版样板用「深黑粗描边 + 高饱和实心糖果」，与现有普通方块
> （半透明冰晶/琉璃、边缘泛白光、内部细裂纹、无黑描边）风格脱节，已按普通块风格重写 A 段。

```
2D match-3 game tile, a single centered square tile with softly rounded corners viewed straight on,
made of translucent glowing crystal glass in {颜色名}: a luminous {亮面} core fading into {暗面}
at the lower right, frosted semi-transparent surface with subtle inner crackle veins like a
gemstone ice cube, a thin luminous rim light {内缘亮线} outlining the edges with a soft outer
glow, NO dark outline, the whole tile looks translucent and radiant against transparency,
gentle inner glow, clean vector-like edges, designed to be perfectly readable at 56x56 pixels,
stylized casual game art, flat shading with glass highlights, transparent background,
single subject, centered composition, no other objects
```

### C 段（负面，逐字复用）

```
no letters, no numbers, no words, no watermark, no logo, no characters, no creatures,
no background, no ground, no shadow cast on background, no photographic texture, no 3D render,
no metallic bevel, no blur, no pixel art, only ONE tile, no offset composition,
no white background, no gray background, no checkered background, no holographic rainbow sheen,
no thick dark outline, no black border, no opaque plastic look, no heavy bevel
```

### B 段（六款形状，逐款固定；符号色取色板「符号」，光晕取「光晕」）

**① row 行爆**
```
the symbol is a bold double-headed HORIZONTAL arrow pointing left and right, with one straight
horizontal impact bar above it and one below it, drawn in {符号} with a soft {光晕} outer glow
```

**② col 列爆**
```
the symbol is a bold double-headed VERTICAL arrow pointing up and down, with one straight
vertical impact bar to its left and one to its right, drawn in {符号} with a soft {光晕} outer glow
```

**③ cross 十字爆**
```
the symbol is a horizontal double-headed arrow crossed by a vertical double-headed arrow forming
a plus shape, with a small round glowing blast core at the exact centre, drawn in {符号} with a
soft {光晕} outer glow
```

**④ split 父雷（图案沿用原版：金色）**
```
the symbol is a large filled WARM GOLD #ffd24a circle at the exact centre, one warm gold plus-shaped
cross passing through it, four short warm gold diagonal lines going toward the four corners, each line
ending in one small round warm gold dot, all in warm gold #ffd24a with a soft amber glow,
the tile otherwise plain
```

**⑤ split 子雷（图案沿用原版：红警三角 + 对角叉）**
```

#22040a, a thin luminous rim light #ff9aa5, NO dark outline, the symbol is a WARNING TRIANGLE outline
in pale red #ff9aa5 with one small round pale red dot inside it, backed by two long crossing diagonal
bars forming an X in bright red #ff4d5e, menacing and clearly different from every other tile
```

**⑥ rand 乱数**
```
the symbol is a square outline rotated 45 degrees into a diamond, containing five round dots
arranged like the five face of a die (four at the corners, one in the centre), drawn in {符号}
with a soft {光晕} outer glow
```

## 5. 生成与验收流程

1. **样板先行**：先出 red × 6 款，确认「玻璃质感 + 形状可辨 + 同色可区分」三件事；这 6 张不过关，不放量。
2. **放量**：样板确认后，按色板逐色替换 prompt（**文生图，不用图生图**——图生图会被上一张的形状先验拉偏，火柱批次已验证过这个坑）。
3. **后处理**：`tools/_special_blocks_build.py` 扩展为按 `chip_<shape>_<color>.png` 命名抠底 → 缩 128 → 输出
   `assets/images/board/special/<shape>_<color>.png`。flood-fill 抠底容差 45，小岛清理，bbox 居中，占画布 88%。
4. **接入**：`special-chip.js` 从「合成」改为「查表取整图」：
   `specialChip(piece)` → `<shape>_<color>.png`（子雷恒 `<sub>`，rainbow 取 `body_rainbow.png`）；
   图未就绪回退现有 `specialBlockMark`。离屏合成与 `source-atop` 代码整段删除，绘制成本降到单次 `drawImage`。
5. **回归**：`_test_special_chip_v11735.mjs` 改为断言「取图路径 + 回退路径」；`_test_pack` / 棋盘冒烟。

## 6. 验收标准（单张）

| 项 | 要求 |
|---|---|
| 尺寸 | 1024×1024 出图，透明底，alpha 通道真实（非棋盘格假透明） |
| 占幅 | tile 占画布 88%，四周留 6% 辉光余量 |
| 描边 | 深色闭合描边，无断口、无外溢 |
| 可读性 | 缩到 56px 仍能一眼认出是哪个形状 |
| 同色可辨 | 同一种颜色下，6 款并排（51px 间距）互不混淆 |
| 灰度可辨 | 去色后仍靠轮廓区分（形状不依赖色相） |
| 画风 | 2D 扁平卡通 + 玻璃高光，与现有三消块同一套光感，不出现写实金属/3D 渲染 |
