## 三、接入代码（两行）

```js
// render.js 顶部
const { createSkillLoadout } = require('./screens/skill-loadout.js');

// Renderer 构造函数内（bind 只做一次，不在每次绘制时绑定）
this._skillLoadout = createSkillLoadout({
  panelShell: this._menuPanelShell.bind(this),   // 必填：270×1060 面板外壳（含 panelClose 命中）
  skillIcon: this._skillIcon.bind(this),         // 强烈建议：缺省会退回「圆底 + 首字」占位图标
  wrapText: this.wrapText.bind(this),            // 建议：缺省用模块内等价实现，测量结果一致
});
```

方法替换建议（保持旧方法名，最小改动、可回退）：

```js
_menuSkillCards(ctx, s, push, label, cfg, x, y, w, h, isMatch) {
  return this._skillLoadout.skillCards(ctx, s, push, label, cfg, x, y, w, h, isMatch);
}
_skillChoiceCards(ctx, s, push, title, slot, items, current, tint) {
  return this._skillLoadout.skillChoiceCards(ctx, s, push, title, slot, items, current, tint);
}
menuMatchCfg(ctx, s, push) { return this._skillLoadout.menuMatchCfg(ctx, s, push); }
menuGlobalCfg(ctx, s, push) { return this._skillLoadout.menuGlobalCfg(ctx, s, push); }
```

`_skillOwned` 暂不删除（商店页 render.js:4410 仍用）；如需统一，可改为转调 `this._skillLoadout.skillOwned(...)`。

## 四、依赖注入契约

| 依赖 | 必填 | 签名 | 缺省行为 |
|---|---|---|---|
| `panelShell` | **是** | `(ctx, s, push, title, hgt, centered, pw) → y` | 缺失时渲染面板直接抛错（不静默降级，避免出现第二套面板样式） |
| `skillIcon` | 否 | `(ctx, id, x, y, size, color)` | 「圆底 + 图标首字」占位（仅预览可用，正式接入必须注入真实实现） |
| `wrapText` | 否 | `(ctx, str, maxW, size) → string[]` | 模块内等价实现（`bold Npx sans-serif` 逐字测量，与 render.wrapText 结果一致） |

**为什么不复制 `_menuPanelShell` / `_skillIcon`**：复制会产生两套样式来源，后续改外壳或换图标必然漂移。`_skillIcon` 属于 D 的 R1 范围，本模块只调用、不实现。
