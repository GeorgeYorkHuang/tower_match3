# Boss体系开发计划与W美工任务单

依据《Boss体系设计》v4，2026-10-30。规划不等于已实现，也不替代原稿待定决策。

## 范围与实施顺序

三场9只Boss，深渊复用圣坛组，测试场不封顶。20/40/60波锁关、阶段技能累计、阶段追加怪、终极路径80%停步；最终60波胜利优先于普通推进。先做圣坛20波垂直切片，验收完整链路后扩展40波分裂及60波终极，再扩熔岩/霜风，最后接专属红与掉落UI。

| 批次 | 主工程交付 | 前置与验收 |
|---|---|---|
| B0 数据合同 | config/bosses.js定义、稳定bossId/skillId、阶段事件和资源清单；只读定义与实例计时分离 | 统一下列歧义，配置校验与旧存档回退 |
| B1 锁关骨架 | 独立boss运行时、锁关/阶段机/阶段出生队列；run/wave由Codex独占接线 | 阈值跨多阶段仍逐一发事件；出生/复活/暂停不重复；Boss死后的残留怪明确处理 |
| B2 圣坛20波 | 藤甲、破壳、幼芽召唤、Boss HUD与资源接入 | 两阶段全流程，盾/甲顺序、控制抗性、阶段追加波5秒内出完 |
| B3 40波双体 | 父遭遇ID、双体实体、共鸣、8秒双杀、单次奖励门禁 | 第一只死不解锁；第二只死才结算；超时回血不重复派奖 |
| B4 终极/多战场 | 三阶段、对峙位、塔debuff/冰封、城墙百分比真伤；9只逐场接入 | 60波胜利/复活保血/撤离深度；普通Boss与test回归 |
| B5 成长经济 | Lv9—14/41—60表、总血口径、裂痕宝箱；先核验并修复碎片入账缺陷 | Boss/追加波/召唤物收益不重复；不可直接改全局maxWave误伤test |

| B7 联调 | 时长与通关曲线、性能/缓存、包体实测 | 用户真机测试；数值按实测调优，文档MB估算不视为平台限额依据 |

计划按交付门禁排序，不承诺未经估算的日历工期。Boss机制放新模块，避免把AI重新堆回combat.js。圣遗物效果仍放relics域，显示放screens/fx，配置放config。

## W美工现在可开工：第一张任务卡

先做圣坛20波萝赛及幼芽完整表现样板：角色透明素材、移动/待机/施法/破壳/死亡、藤甲1—3层、P2花瓣爆裂、召唤入口和阶段切换预警。第二张再做三场20波换皮，随后40波双体、最后3只终极独立8帧主体。原稿3套召唤物之外提及窥视之眼，暂只登记，未定义出生来源前不额外制作。

允许W实现技能表现及独立演示：新增assets/images/bosses/<bossId>/、js/game/fx/bosses/、tools/preview_boss_*.html和配套说明；如果要实现技能逻辑，可在独立js/bosses/skills/中交纯函数/命令输出原型与测试，交给Codex接线，不直接扣血、刷怪、写存档或修改公共伤害。资源ID先按B0清单对齐，演示可先用临时ID，正式资产导入后固定。

禁止与Codex同时改combat.js、run.js、wave.js、main.js、render.js及现有config文件。W只提交自己新增路径，不git add全目录；提交前检查暂存区，避免共享索引收进别人改动。实际消息由owner转发，本任务单未自动发送。

交付合同：manifest包含角色/技能ID、文件路径、帧尺寸/数量、帧率、底部中心锚点、缩放、循环标志、预警/施放/命中/结束时间点和降级方案。表现消费只读事件{encounterId,entityId,bossId,phase,skillId,event,x,y,targets,duration}；技能原型返回命令，由运行时统一执行和判重。演示必须能切阶段/重播/暂停/清场，不接正式玩法。

验收：透明边缘无白底，小尺寸可辨；预警与真实伤害时点分开；特效不盖三消盘/塔槽；低特效模式有简化表现；退出后无残留；图集字节数和峰值同时播放量可查。W附预览和测试，最终真机由用户负责。

## W策划可并行处理：口径校正卡

1. 40波P2具体60%与通用50%冲突，以逐Boss配置待确认，禁止硬写全小Boss50%。
2. 阶梯金率摘要20/26/40与细表精英12、普通20、小26、终极40需统一，原12%逐卡与新箱级不能宣称收益不变。
3. 熔核“死亡伤墙”与“贴墙前清掉”的攻略矛盾，需明确击杀/到墙各自效果。
4. 小Boss击杀后追加怪残留如何处理；双体的父死亡、双杀计时起点、复活保留哪些状态需明确。
5. 圣坛庇护是每次叠层还是持续窗口、P2加速是否刷新；终极停步与P3加速如何共存；多阈值秒杀追加波是否仍生成需明确。
6. Boss血量推导使用名义血与有效血，追加怪也有护甲，应统一有效血预算；不同战场追加量必须分别重算。
7. 炉心容量公式、移速基准、红3星是否继承前星效果、熔芯/暴击溢出分配单位需落为公式。
8. 弹窗“先push先命中”却把全屏遮罩放卡片前的描述矛盾，应按真实命中遍历实现“面板内不关闭、外部关闭”，不能照抄顺序。
9. 既有普通怪血条已隐藏；新增Boss专属HUD单独启用，不能全局重新显示血条。

这些不阻塞外观与技能演示，阻塞对应数值/结算接线。待定问题登记为假设，不静默替owner决定。
