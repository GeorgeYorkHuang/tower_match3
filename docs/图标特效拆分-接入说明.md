# 图标与特效拆分 · 接入说明（D美工/工程师）

- 分支：`feat/icons-split`（基准 `c837306`）
- 提交序列（近→远）：`cced400`（第二批②火柱）→ `ebeff0a`（第二批①火墙）→ `e29038f`（第一批②特殊块）→ `efb1a90`（第一批①技能图标）→ `c837306`（main 基准）
- 原则：只新增模块，**不删除 render.js 原方法**；渲染主体暂留 render.js，由 Codex 集成时替换调用点。伤害时间零改动。
- 全部模块为 CommonJS 纯函数/常量，不 require render.js（无循环依赖）。

| 新模块 | 导出 | 对应 render.js 原方法 | 行号 |

## 第二批：火墙/火柱播放拆分（资源清单 + 选帧/布局/淡入淡出/粒子参数纯函数层）

| 新模块 | 导出 | 对应 render.js | 行号 |

- `fxFireWall` 内：`FW_N/FW_FPS/FW_AR` 与选帧、`FW/FH/bx/by`、`fade`、上升火花参数 → 分别换为 `firewall.N/FPS/AR`、`frameIndex(t,seed)`、`layout(cx,cy,w,h)`、`fade(p)`、`sparkSpec(...)`；贴图路径改从 `firewall.ASSETS` 取值。
