## 模块接口

新增js/game/screens/relics.js，导出createRelicScreen(deps)。依赖：drawImg、relicIconSrc、IMG_SRC、TIER_COLOR、fmtNum、panelShell、wrapText，复用原Renderer的图片缓存/面板外壳/换行，不复制资源加载器。

| 原Renderer方法 | 新绘制器方法 | 兼容方式 |
|---|---|---|
| _menuRelicGrid | _menuRelicGrid | 同参数、push键不变 |
| menuRelic | menuRelic | 新函数返回maxScroll，Renderer写回自身_relicMaxScroll，原方法仍返回undefined |

| _relicRunList/_relicUnlocked/_relicUnlockable/_relicRarColor/_capsuleBar | 同名辅助函数 | 原Renderer方法委托，避免两套实现 |

Renderer._getRelicScreen按渲染实例缓存绘制器；不存页面s、Meta、Run、碎片/星级/金币等玩家数据。menuRelic的滚动上限以返回值交给宿主，模块本身不缓存滚动位置。配置定义速查表移到本模块，表中只有定义引用。

动作仍由input/menu-actions.js及Meta/业务服务处理；绘制函数只画、push命中区，或返回滚动上限。没有读写存档、扣款、发奖和wx触摸绑定。

## 接线

```js
const { createRelicScreen } = require('./screens/relics.js');
// Renderer中懒初始化，panelShell/wrapText绑定一次。
this._relicScreen = createRelicScreen({
  drawImg, relicIconSrc, IMG_SRC, TIER_COLOR, fmtNum,
  panelShell: this._menuPanelShell.bind(this),
  wrapText: this.wrapText.bind(this),
});
// 原入口转调，滚动页需要同步上限。
this._relicMaxScroll = this._relicScreen.menuRelic(ctx, s, push);
```

四个预览构建脚本已补入relics.js，避免file://内联CommonJS加载遗漏。
