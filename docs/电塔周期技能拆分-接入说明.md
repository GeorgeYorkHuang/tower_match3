# R15第十批：电塔周期技能拆分

## 接入与边界

原Combat.tickElectric主体迁到combat/towers/electric.js的tickElectric(combat,dt)，兼容入口保留。计时器、能量、脉冲窗口、Enemy麻痹与fx属于当前实例，模块不缓存状态或修改配置。

包含极光电击主目标、随机分叉/电链再分叉、雷暴随机或高血量优先选敌、连雷/雷霆传播、分批落雷表现与快充脉冲窗口递减。普攻充能、活电弹道推进、状态衰减和公共伤害仍在原模块。

## 保持的顺序与差异

- 极光仍按纵向距离筛选/取最近目标，而非直线距离；主伤即时结算，分叉按原Set去重，再分叉共用该Set，随机效果路径与逻辑随机次数均保持。
- 雷暴仍按原随机洗牌或雷域高血量排序选目标，按y排序演出；雷暴伤害即时结算，只有演出带批次delay，本轮不改成延迟伤害。
- 原C减周期、弱化倍率、耗能后取伤害、无目标仍耗能/复位计时、雷霆麻痹和B连雷顺序不改。
- 脉冲窗口先减dt，可能从正值减为负数；原样保留，不额外钳制。大dt仍至多施放一次，不补发。
- 未改isSkill与P2/P3，未接W反馈/连消功能。

## 验证

`tools/_test_electric_periodic_split.cjs`读取固定c790ce5旧Combat：1536组连续多帧，覆盖双技能开关、分支0~3、圣遗物单独/全开、能量弱化、活/空/射程外/濒死目标、两组随机种子与施放后改攻击力。逐项对比计时/能量、目标/控制、特效路径、调用顺序和随机次数。

额外断言锁定分叉与再分叉不重复目标、极光纵向取敌、雷暴即时伤害而演出延迟、雷域最高血量选敌、无目标施放、脉冲窗口与双实例隔离。

回归通过：电塔攻击1304组、火塔周期496组、冰塔周期256组、公共伤害882组/状态432组/弹道456组、圣遗物击杀1370组/波次554组。W模块的40/44/51独立断言也已核验，尚非接入验收。

本批没有修改页面、资源、伤害事件、Run连消结算或动画阶段。新模块不由Renderer加载，不新增HTML预览内联。
