## 电系：不是整次技能失效

- 球形闪电：1208/1980次雷球脉冲有命中（61.0%），共3031次脉冲目标命中、820次电痕命中；没有完整施法全程零命中。约39%单球脉冲打空与随机漂移/局部覆盖有关，不能把每次脉冲都当作对满范围敌人命中。
- 雷暴：78/116次施法打满配置目标上限；实际453个目标，配置上限合计574个。每次都符合min(出手前射程内存活目标数,配置上限)，未发现明明有足够合法目标却少打的情况。
- 极光电击：没有零命中施法，但本路线选B增伤，主弧80%攻击起、分叉40%主弧，每8秒基础周期耗3能量，实际单次平均收益明显低于另外两项。较低能量同时压低伤害、缩短射程、拉长冷却，但这不是所有电塔技能都该统一增加基础攻击的证据。
- 技能射程按当前inTowerRange的纵向口径验收；没有把普攻欧氏距离选敌规则强行改到周期技能上。

## 冰系：伤害以外的收益

- W25–39实际冰墙吸收合计2503.75伤害，有效到期回血457。同一观察窗到期的名义回血为2600，满血上限等使有效回血只有17.6%；并非漏发。
- 冰缓覆盖移动敌人286.4敌人秒、城墙前敌人72.8敌人秒。麻痹使城墙前敌人停止攻击的观察时间合计47.0敌人秒；后者是所有来源的状态观测，不能全部记作某个电系技能的独占收益。
- 当前路线选冰花B、冬珠C、冰墙C，没有选择“冰冻”技能或冬珠A减速；所以不能把本路线伤害/控制表现推广到全部冰塔构筑。
- 冰花有26/289次完整施法未命中。每次都已生成0.8秒延迟效果，最终范围内无存活目标；需要与瞬发技能区分，不能把这些记录判为技能没有生成。
