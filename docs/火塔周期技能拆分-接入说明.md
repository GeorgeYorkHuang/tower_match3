# R15第六批：火塔周期技能拆分

## 接入与范围

将原Combat.tickFire主体机械迁移到`js/combat/towers/fire.js`的`tickFire(combat, dt)`。原Combat方法保留委托，主update、tickPeriodic、手动周期技施放入口无需修改，执行顺序不变。

本函数负责火柱、烈焰墙、火雨的计时、施放、延迟队列与结算；timers、pillarWaves、fireWalls、rainWaves、groundDots、Run临时增益与Enemy标记仍归当前对局实例。模块不保存玩家或计时缓存，共享数值表保持原引用。

普攻熔炉免费火柱入队在上一批迁移的方法内，本批沿用原消费路径。不改变原技能门控，未激活对应技能时原本不推进的队列也不额外推进。通用地面区域updateGroundDots、主update/reset、统一debuff和死亡协调仍在Combat及已有公共模块，本批不搬；因此不把火塔所有相关代码都宣称已清空。

## 保持原行为

- 火柱先耗能、触发焚天窗口，再筛目标；延迟队列创建帧仍按原逻辑扣dt。中心坐标/半径/主爆炸伤害为入队快照；结算时只给存活中心目标叠熔心，余烬DPS仍在结算时读当前shotDmg。
- 火墙选择射程内y最大的目标，先瞬伤再登记墙。施放帧不扣墙ttl；后续按原tick跳灼烧和C减速，过期移除。射程外火舌倍率与墙内停留增伤计数保留。
- 火雨按原随机顺序生成圈、独立落点与延迟波。普通波使用入队伤害快照，末波天火按结算时shotDmg取值且选择圈内y最大存活目标；伤害、灼烧、燃尽加速小爆炸与表现顺序不变。
- 无可用目标时仍保留原耗能、计时复位与焚天窗口行为。大dt不新增补发周期，不重排队列或改周期余量。
- 不修改任何数值、P2/P3、资源帧、特效播放曲线或伤害时刻。
