# 圣遗物分层图标接入

蓝30、紫23、金12共65张，每张独立透明PNG为256×256。共用三张256×256品质六边形底框，红色圣遗物沿用原图。

资源：assets/images/relics-garden-v1/icons/ 与 frames/。映射及比例：js/config/relic-art.js；分层绘制：js/game/relic-art.js；统一入口：js/game/render.js 的 relicIconSrc / drawImg。

原资源保留，未改名或删除；未修改圣遗物效果、ID、掉落和存档。此版本的新图标和底框可独立更换。
