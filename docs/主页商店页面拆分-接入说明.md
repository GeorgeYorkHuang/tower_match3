# R12 主页与局外商店绘制拆分

- `js/game/screens/home.js`：战场卡、锁定提示、切换箭头、进入战斗按钮和两行技能卡。
- `js/game/screens/menu-header.js`：全宽顶部背景、三横按钮、金币、钻石与测试档案标记。
- `js/game/screens/menu-shop.js`：每日碎片、限购宝箱和技能解锁商品绘制。

模块工厂只保存共享绘制函数，玩家状态每次由参数 s 传入；不持有 Meta/Run，不扣款、不发奖、不写配置。图片加载器仍由 Renderer 共享，技能卡和解锁判定走已有模块。Renderer保留menuBattle/menuShop/_menuHeader入口及原命中键。菜单背景、标题、页签、弹窗路由与共享弹窗壳仍在Renderer。
