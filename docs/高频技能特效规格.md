## 详情

### 1. 多重火球（火塔普攻强化）
- **资源**：程序化。弹体三层焰球（外辉/橙焰/亮心）＋前部焰舌＋三段椭圆火焰尾＋尾迹火星（render 2116-2154）；命中粒子/环/闪（combat 1817-1819）。无贴图依赖。
- **锚点**：塔口 muzzle（combat 1798 `towerMuzzle('fire')`）；弹体中心沿 塔口→目标 连线推进（render 1659-1661 线性插值，末端跟随目标）。弹体放大 `scale`（散射弹 0.9）。
- **演出时间**：弹道 `dur = CONFIG.TOWERS.fire.shot.dur`（越慢弹速越慢）；命中表现 fxParticle 0.35s＋fxRing 0.25s＋fxFlash 0.2s；C 分裂弹 `dur×0.8`。
- **判定范围**：n = count(5)＋A 分支＋焰雨圣遗物（combat 1800）；扇形基准 `fanStep 0.08rad` 两侧均分，中心弹锁定主目标（off=0），散射弹沿途碰撞 `hitRadius 45`（combat 1811/1832）；C 档位式分裂 3/4/5 枚，沿弹道方向 ±60° 均分，`splitHitRadius 30`、`splitDamage 0.25`、`splitDurationRatio 0.8`。
- **回退要求**：无（全程序化，不存在资源失败）。

### 2. 多重冰锥（冰塔普攻强化）
- **资源**：程序化。菱形弹体＋白芯（render 2098-2105）＋冰晶尾迹（2106-2114）；命中粒子/环/闪（combat 2255-2257）。无贴图。
- **锚点**：塔口 muzzle；中心弹 scale 1.15、增殖超小锥 scale 0.38（combat 2243/2268）；弹体中心沿 塔口→目标 推进，中心弹末端跟随主目标。
- **演出时间**：`dur = CONFIG.TOWERS.ice.shot.dur`；命中 fxParticle 0.35s＋fxRing 0.25s＋fxFlash 0.2s。
- **判定范围**：n = count(3)＋A＋暴雪圣遗物；`fanStep 0.08rad` 扇形，中心弹锁定主目标；`hitRadius 45`；C 增殖超小锥 10/14/18 枚各自索敌，`swarmHitRadius 30`、`swarmDamage 0.10`（combat 2230-2243）。
- **回退要求**：无。

### 3. 火雨（火塔周期技，CD 12s）
- **资源**：区域标识圈程序化（双环＋半透明红晕，render 2673-2685）；落点视觉 `fallstrike` 贴图（drawAnimSheet 'fallstrike'/'orange'，96px，render 2698）+ 程序化下落火球段（2693-2706）。
- **锚点**：圈中心 = 随机目标位置 ±20px（combat 2144-2145）；落点 (tx,ty) 为圈内均匀采样（√rand×segR×0.95，combat 2155-2157）；fallstrike 以落点为中心对齐。
- **演出时间**：整波圈 fx `dur = spawnWindow(0.1) + FALL(0.5) + 0.25`（combat 2150）；波内 3 批、每批 2-5 颗、0.1s 内随机错峰生成；单颗下落 0.5s；落地爆焰 0.25s；波间隔 `waveGap 0.5`、基础 3 波＋A 波次；伤害按整波最后落地时刻结算一次。
- **判定范围**：圈半径 `segR = baseRadius(140) × (1 + C 扩张 [0,0.2,0.4,0.6])`（combat 2137）；每波伤害 waveDamage 0.24×（B 档位）；落点视觉半径 `perR 80`（视觉，非判定）。
- **回退要求**：fallstrike 贴图未加载 → 程序化小爆焰（淡出环＋火花，render 2711-2716）；下落火球段本就程序化，无回退风险。

### 4. 冰花（冰塔周期技，CD 8s，延迟结算）
- **资源**：4 帧绽放贴图 `assets/images/icebloom/icebloom1-4.png`（render 1935/1939，按进度选帧）。
- **锚点**：目标位置 (tgt.x, tgt.y)（combat 2471）；绘制尺寸 `fw = fh = r × 1.9`，中心对齐贴图。
- **演出时间**：fx `dur 1.1s`（combat 2471）；4 帧按进度 `frameIdx=floor(p×4)`；**伤害在第 3 帧末结算**（combat 464 注释"冰花第 3 帧末结算"，延迟回调 d.fn）；周期 8s。
- **判定范围**：爆炸半径 `baseRadius 100 × (1 + A 扩张 [0,0.2,0.4,0.6])`；数量 `baseCount 1`＋C 繁花（1/2/3 朵，各目标独立）。
- **回退要求**：贴图未加载 → 六瓣雪花展开＋瓣尖冰晶＋扩散环（render 1940-1959），不出现空技能。

### 5. 冬珠（冰塔周期技，CD 10s，驻场）
- **资源**：程序化。半透明冰球＋高光＋白芯＋外圈呼吸光环＋3 颗旋转冰晶点（render 1810-1831）。无贴图。
- **锚点**：放置点 (sp.x, sp.y) 中心（combat 2495）；光环半径 `r×0.55 / r×0.72` 相对珠体。
- **演出时间**：驻场 `duration 5s`；伤害 tick `defaultTickInterval 0.8s`（combat 2495/2506）；呼吸动画（Date.now 驱动）。
- **判定范围**：珠半径 `baseRadius 110 × (1 + B 扩张 [0,0.2,0.4,0.6])`；驻场内伤害 0.44×、减速 slowMult（A 档位 0.2/0.3/0.4）。
- **回退要求**：无（全程序化）。

### 6. 冰墙（冰塔周期技，CD 20s，城墙护盾）
- **资源**：程序化。垂直渐变冰层（梯形墙）＋顶部 9 根冰刺＋菱形冰晶纹理（2 行×12）＋冰晶粒子＋底部冰雾上浮＋寒光呼吸描边（render 1832-1896）。无贴图。
- **锚点**：城墙基线 `wallY`（render 1836 `this.ly.wallY`）；中心 x=375、`r=700` 覆盖整座城墙（25~725，render 1837 注释）；底边贴城墙线，冰层向上升高 26~30px＋呼吸。
- **演出时间**：驻场 `duration 10s`＋A 凝壁（+2/+4/+6s，combat 2563）；呼吸/冰雾动画全程运行；周期 20s。
- **判定范围**：宽度=整座城墙（r700）；吸收 `absorb 300` 点伤害（combat 2564）；攻击者减速 `attackerSlow 0.4` 持续 2s（config 39）；攻击延迟 0.5s。
- **回退要求**：无（全程序化）。

## 拆分建议（供下一批执行）

1. **冰花**：4 帧贴图路径（`icebloom1-4`）与选帧（`frameIdx=floor(p×4)`）可仿 `fx/firepillar.js` 抽为 `fx/icebloom.js`（资源清单＋选帧＋布局），回退绘制留 render（或一并抽渲染主体，视 Codex 集成节奏）。
2. **多重火球/多重冰锥**：弹道绘制在 `fxShot` line 分支（render 2089-2154），同一处按 key 分支；如需独立调整弹体样式，建议抽 `fx/projectile.js`（line 弹道绘制），与 fxShot 其余 kind 分离。
3. **火雨/冬珠/冰墙**：纯程序化、无资源依赖，暂无需拆分；若后续加贴图，按"资源清单＋选帧＋锚点"同构补齐即可。
4. 所有演出时间轴/判定半径改动，须与 combat 结算时刻（冰花第 3 帧末、火雨整波末、火柱 0.6s）同步确认，不能仅靠数值编辑（沿用第二批任务单约定）。
