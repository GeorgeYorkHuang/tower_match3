# 回旋镖周期与实体拆分接入说明

R15第十五批，固定旧实现基线f9f1a20。

## 接入与状态所有权

js/combat/towers/boomerang.js新增tickBoomerang(combat,dt)、updateStorms(combat,dt)、updateWindTrails(combat,dt)及stepBounce(combat,s,dt)。前三个原Combat入口保持同名委托；stepShot仍先推进s.t，跳过尚未发射的弹道，再将bounce分支交给stepBounce。因此stepBounce不再次累加时间，返回值仍决定弹道保留或移除。

计时器、shots、storms、windTrails与特效队列继续归调用方Combat；每个旋转镖和弹力镖独立持有hitIds。模块只读配置，无运行时缓存。风暴镖与表现共享darts数组，弹力镖与表现保留fx/ref对象关联，结束时同步结束特效。

## 保留的现有行为

风暴镖无目标时消耗施放但不生成实体；弹力镖无目标仍向随机方向发射。旋转小镖命中后保留，同一小镖对同一敌人只结算一次；过期爆炸沿用到期时shotDmg，旋转镖本体伤害沿用施放快照。风暴眼原有最近存活目标规则与计时重置方式不变。

弹力镖保留区域边缘与敌人反弹、同敌伤害去重、反弹增伤上限、次数/寿命终止，以及每个父弹道仅触发一次分裂的标志。子镖沿用原有分裂规则，未新增全局代数限制。风痕保留逐区域伤害、叠加倍率、标记冷却与减速，不按注释重新解释公式或修改平衡；持续伤害事件种类也沿用旧值。P2/P3本批不实施。
