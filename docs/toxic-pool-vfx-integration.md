# 毒池特效与受击反馈

参考 pixelfx nature/toxic-puddle 的油膜、鼓泡及薄雾，重绘俯视毒液池。保留 MIT LICENSE / NOTICE。

资源：assets/images/towers/fx/toxic-pool-v1/。224×160、20 FPS、80 帧、4 秒循环、透明 PNG，锚点 (112,98)，CommonJS 裁帧表。配置：js/config/toxic-pool-vfx.js。

池沿按真实圆形伤害半径映射，0.2 秒淡入，最后 0.45 秒淡出，在敌人下层绘制。每个毒池独立使用真实战斗时间，暂停、倍速、到期与重开同步；加载失败保留程序化池面。

毒池每次实际扣血或扣盾，使用原受击提亮/后震：亮度 0.9，保持 50ms，在后 100ms 淡出；位移幅度普通怪 6px，Boss 3px，衰减振动，仅移动绘制位置。DOT 属性、伤害统计、伤害跳数及叠毒频率保持原逻辑。毒沼、毒棒地面和普通中毒沿用原效果。

自动检查覆盖实际伤害触发、零伤害/范围外不触发、叠加、暂停、倍速、到期、重开、裁帧、图集失败回退与相关召唤物回归。真机视觉表现待确认。
