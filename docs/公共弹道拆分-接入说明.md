# R15第二批：公共弹道拆分

## 接口与边界

新增`js/combat/projectiles.js`，Combat保留四个同名兼容入口：

| 函数 | 职责与归属 |
|---|---|
| addProjectile(combat, shot, visual) | 将原对象登记到当前Combat.shots/Game.fx；保留shot.visual与visual.projectile双向引用，返回原shot |
| resolveShot(combat, shot) | 原target仍存活且仍在当前敌人数组才命中；onHit优先，否则调用combat.hit；不重新索敌 |
| scatterCheck(combat, shot) | 从上次_collisionP到本次进度做线段碰撞，更新当前shot的_collisionP；跳过死怪和ignoreTarget；返回原Enemy引用 |
| sweepPos(shot, progress) | 只计算原有椭圆回旋轨迹位置，不读写Combat，也不推进计时 |

不保留模块级玩家/弹道/敌人状态。碰撞默认半径仍读config/combat-common；没有复制配置。addProjectile的关联对象只能属于当前实例，不能序列化成存档。

stepShot仍负责推进时间、分支判断和返回是否保留；update仍按原顺序移除并标记finished。电球、弹力镖、回旋沿途伤害、风痕和各塔技能/圣遗物逻辑继续留在Combat，避免将塔行为误归为纯几何。未改变伤害公式、周期、随机数、子弹存活期或P2/P3。

## 验证

`tools/_test_combat_projectiles.cjs`固定读取5e6046f旧Combat源码：

- 384组散射碰撞：不同方向、零长度线段、进度/上次进度、半径、敌人顺序及忽略目标；比较返回对象身份与shot变更，检查敌人输入未变。
- 28组回旋轨迹：水平/竖直/斜向/重合起终点及多种进度。
- 8组终点命中：活目标、死目标、离场和无目标；默认/自定义回调。
- 36组真实stepShot推进：普通、自定义、散射、回旋，延迟发射、未结束与跨过终点。
- 额外断言：visual双向引用、散射大步长先撞近敌、碰撞移除后不再命中第二只、主目标死亡不取消第二条独立弹道、另一个Combat实例不受影响。

相关回归通过：目标选择648组、多重火球/冰锥及延迟发射、焰雨3★、圣遗物击杀1370组、波次554组、撤离检查点11项。

本批未重跑/修改旧技能页面几何对比；W的新规格下，原触摸测试的连消配置用例仍待同步。未改动美术资源及其工作区文件。该模块不由Renderer加载，HTML绘制预览不需额外内联。

## 用户设备抽查

1. 多重火球/冰锥中，第一条命中后其余弹道仍继续独立飞行与命中。
2. 散射/碎冰子弹命中一只怪即消失，不穿透；倍速下仍能命中。
3. 回旋镖飞行轨迹与之前一致。
