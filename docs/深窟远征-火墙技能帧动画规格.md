## 2. 播放规格（引擎无关）

| 项 | 值 | 依据 |
|---|---|---|
| 帧率 | **12 fps** | 档位表取值；火焰抖动 12fps 足够流畅 |
| 帧数 | **4 帧** | 用户指定 |
| 时长 | 0.333 s/循环，`loop` 循环播放 | 火墙持续 6s ≈ 循环 18 次 |
| 三段节奏 | 燃起(f1) → 右倾高峰(f2) → 中部落谷(f3) → 反弹最高(f4)→回 f1 | 相位差明确，循环无跳变 |
| 帧事件 | 无 `hit_frame`（伤害由 `combat.js` 逻辑结算，动画纯演出） | 伤害每 0.5s tick，与帧解耦 |
| 混合模式 | **source-over 主体 + 45% lighter 辉光叠加**（v1.17.18 修订） | 见 §6.1 修订原因 |
| 叠加上限 | 同屏 ≤2 面火墙 × 4 帧 = 全部驻内存（211KB） | 预算内 |

## 3. 游戏内接入参数

- 绘制尺寸：宽 **180 逻辑px**（与现有火墙 `f.w` 一致），高按画布比例 160/512 → **56 逻辑px**（现有墙体 45px + 焰尖超出 11px，压不住判定框）；
- 锚点：画布**底边中心**对齐 `f.y + f.h/2`（地面线）；
- 淡入淡出沿用现有 `fade` 曲线（前 10% 淡入、后 15% 淡出），用 `globalAlpha` 乘在加法绘制上；
- 接入点：`render.js fxFireWall()` 内替换「主火焰条 + 亮芯」两段程序化绘制，保留「地面红晕 ellipse」与「上升火花」两层代码层（粒子层与贴图层叠加，层次更活）；
- 生成时 `drawImg` 需临时设置 `ctx.globalCompositeOperation = 'lighter'`，画完恢复 `'source-over'`。

## 4. 后处理流水线（可复现）

`tools/_fx_firewall_v11716.py`：
1. 水印擦除——右下角低饱和灰白像素（|R−B|<35 且 V>25）压黑，保住高饱和橙色余焰；
2. 黑底地板——全帧减 14，消除原图 ≈10–15 的非纯黑底（加法混合下会显形为面板）；
3. **四帧同一全局 bbox 裁剪**（保证逐像素对齐，火焰不跳）→ 等比缩放 512×160 居中；
4. 接触表 + 12fps GIF + 战场加法混合模拟图。

`frame_check.py --fps 12` 结果：**PASS**（帧号连续 1–4、尺寸统一 512×160、时长 0.33s）。
唯一 WARN：高度 160 非 2 的幂——canvas 2D 直绘无影响；如未来进纹理图集压缩，重排到 512×256 画布即可。

## 6. 接入实现（v1.17.17 接入 / v1.17.18 混合修订）

### 6.1 混合模式修订（v1.17.18）

v1.17.17 首版按"火焰=发光体"走全加法混合（黑底即透明），但严格比例验证发现两个问题：

1. **暗红底与描边丢失**：这张精灵图是带描边的卡通形体（非纯光斑），加法会把 #e74c3c 暗红底和深色描边冲成发白的黄——卡通质感没了。现有 `anim_explosion` 爆炸表是纯光斑所以适合加法，两者材质不同不能同一口径；
2. **亮底冲淡**：远古战场（默认）与测试战场回退亮草地背景（`action_area_edges.jpg`），加法在亮底上把火焰洗成近白。

修订：帧资产转为**透明底 RGBA**（亮度通道 alpha：V<16 全透明 / V≥100 不透明），主体 `source-over` 绘制保色，再同帧叠加一遍 `lighter` @45% alpha 给暗色战场熔光感。工具：`tools/_fx_firewall_alpha_v11718.py`。

### 6.2 落地明细

| 项 | 实现 |
|---|---|
| 资源路径 | `assets/images/fx/firewall/anim_firewall_01..04.png`（assets 为分包，**透明底 RGBA**），`IMG_SRC.firewall1..4` |
| 取帧 | `fi = floor(f.t * 12 + seed * 1.7) % 4 + 1` —— 12fps 循环；**按 seed 错相**，同屏多面火墙不同步播放 |
| 绘制 | `globalAlpha=fade` source-over 主绘制 → 命中后再 `lighter` @ `fade*0.45` 叠加同帧（save/restore 包裹） |
| 尺寸 / 锚点 | 宽 = `f.w`（180）、高 = 180×160/512 ≈ **56**；底边对齐 `f.y + f.h/2`（地面线），水平居中 |
| 保留的代码层 | 地面红晕 ellipse（有效 alpha≈0.10，很淡）+ 上升火花 5 颗（粒子层与贴图层叠加） |
| 回退 | 4 张贴图未加载完成时走 `_fxFireWallProc()`（v1.16.21 原程序化火焰条 + 亮芯），**不出现空墙**；回退路径不产生 lighter 残留 |
| 预加载 | 首次绘制时一次性 `loadImg` 拉起 4 张，避免逐帧加载抖动 |
