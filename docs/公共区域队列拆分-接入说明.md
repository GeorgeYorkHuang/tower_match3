# 公共延迟爆炸与地面区域拆分接入说明

## 接口和数据隔离

新增js/combat/areas.js，导出updateDelayed(combat,dt)、updateGroundDots(combat,dt)。原Combat同名入口保持委托，更新顺序不变。delayed与groundDots始终属于调用方Combat，敌人状态属于对应敌人实例；模块无共享可变状态，也不复制或缓存配置/游戏实例。

延迟任务仍倒序推进，先从队列移除，再执行fn(combat)或爆炸。自定义回调继续接收原Combat，回调追加的末尾任务不在当前轮补执行。普通落点保留空袭追加随机爆炸、焦土区域生成与伤害读取时机。公共爆炸、伤害和叠毒/减速复用原Combat接口，伤害数字链路不变。

地面区域仍先扣寿命，过期后不结算末跳；存活区域保持原直伤、毒沼减速、每秒叠毒、边缘毒环与毒云扣能量顺序。原区域级_t/_ft累积及毒云扣能量频次保持不变，不在重构中改为每敌计时或按秒扣能量。焦土使用fire来源、0.24倍系数与持续区域的原伤害事件分类也保持不变，P2/P3留后续独立任务。
