# 六塔扣费规则（已接入）

日期：2026-11-10；基于 V1.18.9。城墙破防修复与扣费规则均已接入：缺能继续释放、扣光剩余能量，按出手前能量计算本次伤害。普攻强化使用各技能独立配置的能耗系数，仅激活计一次、不同技能相乘、分支升级不额外叠加次数。基础攻击、技能伤害系数、基础普攻费和周期技能费保持原样。本文件不代表已发布新版本。

## 当前实际费用

### 普攻：每次攻击动作收一次

| 塔 | 无强化时每次基础费用 | 当前强化收费依据 |
| --- | ---: | --- |
| 火 | 35/60 ≈ 0.5833 | 多重火球、大火球的预期直伤/溅射/附加灼烧 |
| 冰 | 24/60 = 0.4000 | 多重冰锥与穿透的预期输出相乘；仅学其中一个时单独计算 |
| 毒 | 16/60 ≈ 0.2667 | 剧毒的预期完整持续伤害 |
| 电 | 30/60 = 0.5000 | 连锁预期目标、导电与高能共振 |
| 回旋镖 | 26/60 ≈ 0.4333 | 同轮多镖的同倍率伤害总和、折返增伤 |
| 炮 | 60/60 = 1.0000 | 重炮预期溅射、双管/追炮概率、军火库高能增伤 |

当前费用 = `基础普攻费 × max(1, 综合预期输出倍率) × 已激活技能A的能耗系数 × 已激活技能B的能耗系数…`。每个技能只在激活后提供一次自己的系数，不按技能等级或分支选择次数重复乘。原有预期输出倍率仍按当前分支效果变化；折算后不再设1倍下限，让总输出倍率为1的小冰锥等强化也能获得能耗收益。

Boss收费沿用这套预期输出口径；即使只有单个Boss也不按实际溅射人数降低费用（已确认保留）。

各技能折算配置位于 `js/config/tower-skills.js` 的对应技能对象，字段为 `attackEnergyFactor`；没有全局0.8参数，也没有代码中的统一折扣默认值。当前参与原普攻倍率计费的13项各自配置为0.8，后续可以分别改为0.9、0.7、1等值。未配置、未激活的技能按1处理，不提供折算。

| 塔 | 已配置独立系数的技能 |
| --- | --- |
| 火 | 多重火球、大火球 |
| 冰 | 多重冰锥、冰穿刺 |
| 毒 | 剧毒 |
| 电 | 连锁、导电、电磁过载 |
| 回旋镖 | 多镖、折返增伤 |
| 炮 | 重炮、双管齐射、军火库 |

这些技能在激活后即提供自己的系数；高能量增伤是否满足条件仍独立判断。多重冰锥与冰穿刺先合并两者的预期输出，再各自提供一次独立系数。它仍按预期能力定价，不按本次实际命中数结算；多弹、多目标和持续伤害本身不会再逐次收费。

刚学到技能、无分支/圣物加成与免耗时：

| 普攻强化 | 未折算费用 | 最终费用（每技能当前配置0.8） |
| --- | ---: | ---: |
| 多重火球 | 0.77 | 0.616 |
| 多重冰锥 | 0.66 | 0.528 |
| 连锁 | 1.20 | 0.96 |
| 重炮 | 2.20 | 1.76 |
| 重炮＋双管齐射 | 2.75 | 1.76（2.75×0.8×0.8） |

独立调整例：重炮设为0.65、双管齐射设为0.9时，两者组合费用为2.75×0.65×0.9＝1.60875；冰塔和其他技能不会跟着变化。

原先不计入普攻倍率的其他被动、周期技能和全局技能，本次不新增收费，也不自动增加折算配置。该系数根据当前激活状态实时计算，不另存永久累乘值；重开不会继承上局，读档或重复读取也不会重复叠加。

普攻先找目标；没有目标不收费。费用不足时先尝试借用备用能量库，仍不足则扣光余量，继续攻击。借用完成后、扣费之前记录本次能量档位；本次伤害使用该档位，返能不再反过来改变已经出手的伤害。

一次召唤多根毒棒/多个炮台，仍仅收该次技能费用；驻场攻击、区域持续伤害不逐跳收费。

`castEnergy` 不借备用能量，足额扣除、不足扣光，零能量仍释放；返回扣费前能量供本次伤害与选点使用。需要目标的攻击型周期技能无目标时不扣费、不重置冷却，等待目标进入范围后立即施放。

冰墙、地雷阵、球形闪电、弹力镖保留空场施放：它们会真实生成护盾、地雷或自由移动弹体，并非失败空放，因此照常收费。

配置表中的“活电1、风痕1”没有对应的 `castEnergy` 调用，不能当作当前真实额外消耗；瘴气配置0。不能只看配置表就累计所有技能能耗。

### 三消联动和全局技能

- 三消额外攻击 `bonusStrike`：收该塔基础普攻费，未叠加普攻强化收费倍率；先找到目标再收费，本次伤害读取出手前档位。
- 连消方块转子弹 `spawnChainShots`：当前不扣塔能量；0能量时有移除30%弱化的特判，低于20但大于0时仍保留低能伤害倍率。
- 全局技能使用自己的弹药/充能，不混扣塔普攻费用。
- 免耗与返能依照各自圣遗物、天赋、分支生效；回旋镖免耗退款只退本次实际扣除量，两种免耗同时触发也不重复退款。

## 统一执行规则

1. **缺能继续释放**：普攻、周期技能都可继续；费用足够则全扣，不足则扣光剩余能量，不允许负能量，也不允许不足费用就整次免单。
2. **先确定本次能量档位，再扣费**：如使用备用能量，先完成允许的借用，再记录扣费前能量。用此档位确定本次能量伤害倍率，避免“差一点能量却比刚好够能量打得更强”。同次攻击/召唤的后续输出沿用该次能量倍率，后续敌方护甲、易伤照原有命中规则处理。普攻射程在选中目标时单独快照，多重火球、冰锥/穿透和同轮齐射保持该轮弹道长度；借能、扣费或返能不再缩短已经锁定的轨迹，下一次普攻重新按当前能量选敌。
3. **真正出手才收取**：需要目标的攻击技能先找到合法目标，再收费并重置冷却；空场等待时不扣费、不丢已就绪的技能。冰墙、地雷阵、球形闪电、弹力镖成功生成实体即算施放，不要求攻击目标。
4. **每次动作只收一次**：强化普攻使用基础费×综合预期输出倍率×各已激活技能独立系数，每技能计一次，分支升级不增加折算次数；未强化普攻保留基础费。周期技能使用上述固定费。穿透、溅射、连锁、召唤物后续攻击、灼烧/中毒持续伤害不再重复收费。原有群体预估系数保留。
5. **保留明确的免费来源**：连消转子弹、明确标注的免费触发仍免费；三消额外攻击继续按基础普攻费，不能又叠一次强化费。免耗不先扣后凭名义费用返还，返能和免耗需分开结算，避免制造额外能量。
6. **备用库和同帧顺序**：备用库仍只供普攻及三消额外攻击借用，周期技能不借用。同帧多个技能按实际出手顺序分别记录当次能量、分别扣费，不共用帧初余额，不预支未来充能。

例：技能费用2，出手前能量1.9/2/2.1，修复前分别按60%/30%/60%伤害释放，扣费0/2/2；现在统一为按60%伤害释放，扣费1.9/2/2，余量0/0/0.1。

### 能量档位沿用现值

| 出手前能量 | 伤害倍率 | 周期冷却倍率 |
| --- | --- | --- |
| 0 | 30% | 2倍 |
| 大于0、小于20 | 60% | 1.5倍 |
| 20至40 | 60%线性升至100% | 1.5倍线性降至1倍 |
| 40至90 | 100% | 1倍 |
| 大于90 | 每多1点约加3%，100点及以上封顶130% | 1倍 |

能量同时影响射程。配置中的普通攻击间隔倍率尚未接入实际普攻调度，不能将其当作已经生效；本次统一扣费也不顺带增加这一层攻速惩罚。回旋镖仍使用往返飞行/接镖节奏。
