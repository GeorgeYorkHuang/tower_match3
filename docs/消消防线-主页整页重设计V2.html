三、V2 改动清单（对应 8 条反馈）

① 安全区：y=196 以上为系统区（状态栏 + 灵动岛/胶囊），品牌标题、货币胶囊全部下移至 y≈236；右上角 200×64 永久让位给小程序「···/⊙」胶囊；底部保留 26px 家园条安全区。
② 更名：「消消防线」→「消消堡垒」（备选：弹雨堡垒 / 消塔回响）。
③ 附着式页签：四页签改为全宽通栏 dock（h128，含底部安全区），无浮动间距、无圆角悬浮卡；激活项以主题色整格填充 + 顶部 4px 指示条附着于底边。
④ 圣遗物详情卡：640×1200 竖版卡片；上 1/3 图标区（径向光 + 196 图标 + 名称 40）；三星介绍自下而上 1★→3★，当前级金框；胶囊进度条 h64（文字 22 居中在胶囊内），立体感 = 深色内凹槽 + 填充顶部内高光 + 底部暗缘 + 外发光投影；底部升级按钮左侧「升到 3★」、右侧银币图标 + 数量，中缝分隔线。
⑤ 技能弹层：顶部主题丝带「技能升级·三选一」，150px 大技能图标 + 40 号名称居中；三张分支卡带大图标、A/B/C 徽标列、右上状态章（已选 ✓ / 可选 / 2★ 解锁），底部通栏确认按钮。
⑥ 塔图鉴：页签 6 等宽（702/6=117）无缝拼接、竖线分隔；技能卡删右下「详情」；能耗在塔面板与技能卡上均为 ⚡ 胶囊（深色内凹 + 金色描边）。
⑦ 圣遗物图鉴卡：与详情卡同款胶囊进度条——文字 16 居中在胶囊内，胶囊 h36 = 文字 16 + 上下各 10；立体感同规格缩小。
⑧ 战场切换箭头：双层青绿渐变 V 形箭头（参考你给的图），76×100，带黑色投影；左侧箭头朝左（上一个）、右侧箭头朝右（下一个），反向那版已修正。
