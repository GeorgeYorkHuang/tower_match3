# 回旋镖攻击与命中拆分接入说明

R15第十四批，旧实现基线a09277f。

## 接口与所有权

新增js/combat/towers/boomerang.js，导出hitBoomerang(combat,e,dmg)、sweepDamage(combat,s)、tickAttack(combat,dt)、launchAttack(combat,params)、tryAttackDebuff(combat,o,dmg)。Combat保留hitBoomerang和sweepDamage同名委托，tickTower、attackOnce、tryAttackDebuff仅将回旋镖分支转调新模块。launchAttack参数为原攻击上下文key/target/dmg/dur/sx/sy/tint/baseShot。

配置来自config与tower-skills，只读；bWait、bCatch、_nextDmg、shots、windTrails继续归调用方Combat，标记/流血与hitIds分别归敌人/弹道，模块不缓存游戏实例。攻击消耗、接镖回能概率、全局齐射仍在公共attackOnce，先后顺序未变。流血施加与实际伤害继续使用公共statuses/damage，伤害数字继续显示实际生命损失。

## 行为边界

保留飞镖在途不再投掷、未学接镖等待原0.5秒、学后即时续投、疾接加伤/无敌窗口、多镖独立索敌及每镖独立hitIds。直接命中先叠猎手标记，再伤害/流血/折返；sweepDamage保持独立扫伤路径，不改为调用hitBoomerang。强返与镖群的额外命中标志沿用原逻辑，不借拆分修改回程条件。风痕只迁移生成/间距/上限判定，持续区域推进留待下批。

风暴镖、弹力镖周期与旋转/弹跳实体、风痕区域推进、死亡协调和公共主循环仍在Combat。P2/P3、Boss设计文档本批未实施。
