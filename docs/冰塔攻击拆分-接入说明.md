# R15第七批：冰塔攻击与命中拆分

## 接口与边界

新增`js/combat/towers/ice.js`，导出_iceMultiShot(combat,e,dmg)、hitIce(combat,e,dmg)、iceHitFx(combat,enemy,damage)，Combat同名方法保留委托，所有旧调用点不变。

- _iceMultiShot：中心直瞄/侧向散射、多重冰锥C增殖各自索敌、命中时统一debuff和暴雪冰爆。
- hitIce：单发伤害与追加冰锥、冰雾扩散/地面、碎冰子弹、冰穿刺投影/扇形与冻结。
- iceHitFx：暴雪3★已减速目标的概率冰爆。

模块只持有共享配置，不缓存Combat/Run/Enemy；弹道闭包绑定当前实例，沿用公共弹道、伤害和状态接口。冰雾产生的iceGrounds继续由原周期逻辑消费。

跨塔attackOnce、hit、电磁场、统一tryAttackDebuff、freezeE/applySlow及圣遗物死亡入口不迁移；tickIce/冰花/冬珠/冰墙留下一批。没有把“冰穿刺”与“不穿透碎冰子弹”合并；冰穿刺原有即时目标结算语义保留。

## 保持的行为

- 多重冰锥替代单发；中心弹、侧弹和增殖均在真实命中时结算，不额外即时扣主目标血。
- 增殖按存活且在范围内的敌人循环分配方向，无候选回退传入主目标。
- 子弹命中后消失，独立弹道不因主目标死亡取消。
- 碎冰从越过主目标的偏移点生成，C分支概率冻结保持直接写入方式，不改走另一个冻结入口而新增圣遗物返能。
- 冰穿刺按原投影排序与数量结算，C扇形、穿透凝冰末目标冻结和暴雪判定顺序不变。
- 不调整数量、伤害、概率、星级收益或P2/P3。

## 验证

`tools/_test_ice_attacks_split.cjs`以固定37d32c5完整旧Combat为基线：

- 1024组：三个迁移入口及attackOnce，三技能8种开关组合、分支0~3、星级0~3、两种随机种子。
- 发射后推进初始弹道并执行后续子弹回调；对比目标状态、冻结减速、冰雾地面、能量、弹道/表现、伤害/debuff/特效调用与随机次数。
- 额外断言：多重替代单发、一次攻击只扣一次能量、发射时不提前伤害、侧弹不依赖主目标存活、增殖多方向与无候选回退、碎冰首碰消失、双实例隔离。

回归通过：火塔攻击1024组、火塔周期496组、公共状态432组/伤害882组/弹道456组、火冰多弹道、火冰命中配置读取、圣遗物击杀1370组与波次554组。

本批不修改UI/资源；子雷改白色属于独立提交与绘制验证。新模块不由Renderer加载，无新增HTML绘制预览内联依赖。

## 用户设备抽查

1. 多重冰锥正常替代单发；C增殖无即时主目标伤害，冰锥各自命中。
2. 碎冰碰怪后消失，不连续穿透；冰穿刺自身的贯穿/扇形效果仍正常。
3. 暴雪冰爆、冰雾扩散及冻结/减速正常，主目标死亡后侧弹继续飞行。

真机由用户执行。下一批冰塔周期技能：冰花、冬珠、冰墙及相关队列。
