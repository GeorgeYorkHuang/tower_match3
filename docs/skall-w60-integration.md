# 斯卡尔 W60 首版接入

霜风峡谷 W60 注册 `frost_skall`，final 标记沿用终局胜利入口。首版生命281000、护甲20%、速度系数1.55，免疫冻结/击退，路径80%停步。生命按当前薇拉预算同比折算，未完成实战平衡。

- P1 寒风：每10秒全塔攻击间隔×1.3，持续3秒。
- P2 霜影：70%进入阶段2，70%和40%血量阈值各生成2只霜影；40%不是阶段3入口。单次大伤害可触发两组，重复伤害不重复生成。霜影生命1405、移动系数2.2，出生队列和总血记账同源。
- P3 冰封：35%进入阶段3并追加本阶段怪；每15秒选至多2座不同的已激活塔，先预警1秒，再封4秒。已发射弹道/地面伤害/召唤物继续结算；新普攻停止，周期技能暂停冷却且不得新施放。解封恢复原冷却进度。寒风继续生效。
- 随机选择使用无放回抽样，少于2塔时只选现有激活塔；不生成空槽目标。冻结/预警保存在当前遭遇，死亡后清空。

表现：简版阶段血条、寒风提示、目标塔位预警框、冰封交叉标记与剩余秒数。本体及霜影仍为占位，独立美术agent提供的草案尚未接入。

验证：`node tools/test-frost-skall.cjs` 通过，覆盖阈值跨越/生成去重、寒风恢复、不同塔位预警/冻结起止、普攻直接施放门禁、周期冷却暂停和已生成效果继续推进、召唤物速度、死亡清理、长帧事件推进。伊格尼斯/卡洛斯/维尔德三组生命周期回归通过。尚未验证完整微信战斗的伤害/操作/倍速观感。
