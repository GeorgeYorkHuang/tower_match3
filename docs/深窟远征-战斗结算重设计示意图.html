与现版的差异（为什么这样改）：
  • 全屏三段式，替代 620×760 小面板：结算是一局的情绪顶点，值得整屏；顶部舞台/中部战利品/底部账单，视线自然从「结果 → 收获 → 行动」。
  • 深度轨迹条（新增）：撤离点画成旗标、本局终点高亮——一眼看到「我走了多深」，强化 Roguelike 历程感，也为后续「难度超车」版本的检查点冲刺做视觉铺垫。
  • 圣遗物从一排小圆点 → 大卡片：图 52px + 名称 + 稀有度边框色 + 碎片 ×n 角标，SSR 金边；一屏最多 2~3 张，更多折叠为「共 N 件」。碎片数量直接挂在所属圣遗物卡上，不再单独一行。
  • 账单图标化：金币 / 宝箱均为 图标 + 数量/档位，无文字描述；宝箱注明「已存入仓库」去处。
  • 失败态同构不同色：结构不变降低理解成本，红调 + 圣遗物卡灰化 + 「保底 30%」角标，损失有交代、不羞辱玩家。
  • 英文绶带（EXPEDITION CLEAR / LINE BROKEN）纯装饰字，拉质感、不占信息位，可换拼音/去字。
