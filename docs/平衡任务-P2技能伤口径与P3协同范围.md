## 二、P2：`isSkill` 口径不一致

### 2.1 机制定义（只有一个消费者）

```js
// js/combat.js:187
shotDmg(key, isSkill) {
  ...
  if (isSkill && run.chargeSkillBoost > 0) dmg *= (1 + run.chargeSkillBoost / 100);
}
```

- `isSkill` **全代码库唯一作用**：让「全局充能3★」的 `chargeSkillBoost` 生效（`js/run.js:433`，每次充能溢出 +10%，上限 +50%）。
- 不动 `isSkill` 的口径，就等于决定「哪些伤害吃这 0~50%」。
- 现状是**调用方各自手写布尔值**，没有任何一处集中定义，因此逐版本漂移。

### 2.4 调整前后影响

**公式**：`塔伤提升 = 技能伤占比 × (1 + i)`，`i = chargeSkillBoost/100`，上限 `i = 0.5`。

**受影响技能的理论秒伤贡献**（单位：÷ 该塔 dps；无分支、全命中的上界值）

| 塔 | 技能 | 周期/系数 | 贡献 |
|---|---|---|---|
| 冰 | 冰花 0.8 / 8s | — | 0.11 |
| 冰 | 冬珠 0.44 × 6 跳 / 10s | — | 0.29 |
| 电 | 雷暴 0.64 × 3 目标 / 10s | — | 0.19 |
| 电 | 极光电击 0.8 × 2 目标 / 8s | — | 0.20 |
| 毒 | 毒池 0.20/s × 4s / 5s | — | 0.16 |
| 毒 | 毒棒 0.24/s × 10s / 10s | — | 0.24 |
| 炮 | 炮火支援 0.60 × 3 目标 / 12s | ×1.8 间隔 | 0.27 |
| 炮 | 炮台 0.68 / 0.9s（8s 存续） | ×1.8 间隔 | ≈1.0（受命中率折损，存疑，须实测） |
| 回旋镖 | 弹力镖 0.60 × 2 枚 / 8s | ×1.3 间隔 | 0.20 |

**结论量级**：改后单塔 DPS 上限提升约 **+8% ~ +25%**（i=50% 满层时），**炮塔最高、冰塔最低**；且只在「拿到全局充能3★ 且反复溢出堆满」这一稀缺路径上体现，属**上限抬升**而非平均抬升。基础 6 塔数值、关卡曲线不需要动。

### 2.5 验收门槛

1. 木桩场景固定种子，强制 `chargeSkillBoost = 50`，记录 30 秒各塔总伤：改后 17 项各 ×1.5（±1%）；
2. 碎冰 / 火焰弹射 / 散射火球 / 普攻主路径 改前改后偏差 ≤0.5%；
3. 关闭充能3★（`chargeSkillBoost = 0`）时，全场景输出逐帧一致（等价性回归必须 0 差异）。

### 3.2 预期规则（候选）

| 方案 | P3-b（explode） | P3-a（towerDps） | 评价 |
|---|---|---|---|
| **A（推荐）** | 收窄到 `key === 'cannon' || key === 'fire'` | 收窄到 `key === 'ice' || key === 'electric'` | 语义最自洽：「组合」= 两塔的伤害被加强 |
| **B（折中）** | 保留全局，文案改成「爆炸伤害 +50%」（视为通用爆炸增益） | 收窄到冰/电 | 改动小，但协同[1] 名不副实（两塔达成 → 全爆炸增强） |
| C | 现状即设计，只补文档 + UI 说明 | 同左 | 零风险，但「旗舰组合」概念废掉，后续加协同组会继续堆叠全局乘区 |

### 3.3 调整前后影响

**P3-b（收窄 explode）**
- 冰塔：C3 碎裂单次击杀 AOE 由 `1.5 → 1.0 shotDmg`（协同下），**-33%**；冰塔本就不靠爆炸主输出，属局部回收。
- 毒塔：毒爆 `0.3 → 0.2`，影响可忽略（毒爆主要价值是传染）。
- 回旋镖：旋风3★ 结束爆 `1.5 → 1.0`，**-33%**，圣遗物 3★ 收益下降。
- 三消：全塔 5/6 消溅射 `-33%`（协同下），**这是唯一影响所有塔的一条**，属常规输出回收，需在关卡曲线复测中确认漏怪率不上升。

**P3-a（收窄 towerDps）**
- 协同[0] 达成后，火/毒/炮/回旋镖 从 ×1.5 掉回 ×1.0 → **该四塔输出 -33%**。
- `run.js:632` 波末漏怪结算用的是 `totalDps()`（含同一乘区）→ **城墙掉血同步上升**，难度曲线整体抬高，不是只改数字。
- 因此 P3-a **不建议与 P3-b 同批**，且必须配补偿（三选一：给非冰电塔「协同次级收益 +15%」/ 提高协同[1] 到 +80% / 降低 30 波后的怪物代际斜率）。

### 3.4 验收门槛

1. `synergyDone[1] = true` 时，断言 ice / poison / boomerang 的 `explode` 入参伤害与 `synergyDone[1]=false` 时**逐值相等**；cannon / fire 仍 ×1.5。
2. `synergyDone[0] = true` 时，断言火/毒/炮/回旋镖 的 `towerDps()` 与未达成时相等；冰/电 仍 ×1.5。
3. 波末 `settleWave` 的 `leak` 在固定种子下与改前比对，落差需在策划给定容忍带内（P3-a 必测）。

## 五、顺带发现（不在本任务范围，仅登记）

**P4 候选：跨塔借用伤害基准。** `472`（炮·焦土地面）与 `3050`（炮·火线地面）都是 `shotDmg('cannon', true)` 生成 `key:'fire'` 的持续区——伤害基准取炮塔、伤害归属算火 DoT。P2 统一口径（技能真）后，这两处会同时吃 `chargeSkillBoost` 且被算作火系持续伤害，口径更混乱。建议并入战斗层重构，本轮不动。
