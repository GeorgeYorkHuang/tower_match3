## 二、P2：`isSkill` 口径不一致

### 2.1 机制定义（只有一个消费者）

```js
// js/combat.js:187
shotDmg(key, isSkill) {
  ...
  if (isSkill && run.chargeSkillBoost > 0) dmg *= (1 + run.chargeSkillBoost / 100);
}
```

- `isSkill` **全代码库唯一作用**：让「全局充能3★」的 `chargeSkillBoost` 生效（`js/run.js:433`，每次充能溢出 +10%，上限 +50%）。
- 不动口径，就等于决定「哪些伤害吃这 0~50%」。现状是**调用方各自手写布尔值**，无集中定义，因此逐版本漂移。

### 2.2 分类口径（本提案的核心，先定这个再改代码）

| 分类 | 含义 | 应吃加成 | 典型代表 |
|---|---|---|---|
| **A 普攻** | 塔的常规攻击本体 | 否 | `attackOnce`、`bonusStrike` 三消额外攻击、`spawnChainShots` 连消连锁弹 |
| **B 普攻强化** | 挂在普攻弹道上的附加物（附加/多重/散射/贯穿/碎片） | 否 | 火焰弹射、焰雨散射火球、碎冰 3 片 |
| **C 周期技** | `castEnergy` / `timers` 驱动的主动技及其衍生（含 3★ 触发的技内爆炸） | **是** | 火柱、烈焰墙、火雨、冰花、冬珠、雷暴、极光电击、过载、毒池、毒棒、炮火支援、地雷阵、炮台、风暴镖、弹力镖 |
| **D 持续区 / DoT** | `groundDots` / `windTrails` / 毒棒 / 叠毒 / 灼烧 | **是** | 毒池叠毒、风痕、火线、毒痕、电痕 |
| **E 死亡触发** | `onKill` 内的死亡技 | **是** | 爆燃、毒爆、碎裂、燃烧弹3★、血刃3★ |

**判定式：`isSkill = 分类 ∈ {C, D, E}`。**

### 2.3 现状统计（详见附录 A）

| 分类 | 调用点 | 现传 true | 现传 false | 结论 |
|---|---|---|---|---|
| A 普攻 | 3 | 0 | 3 | 正确 |
| B 普攻强化 | 3 | 0 | 3 | 正确（保持） |
| C 周期技 | 26 | 10 | **16** | 漏 16（含 `2040` 归 C/D） |
| D 持续区/DoT | 13 | 12 | **1** | 漏 1（`385`） |
| E 死亡触发 | 12 | 12 | 0 | 正确 |
| **合计** | **57** | **34** | **23** | 需补 **17** |

- **漏传 17 处**：冰 3 / 电 6 / 毒 2 / 炮 3 / 回旋镖 3。
- **最强证据是内部矛盾**：地雷阵**弹片** `617` 传 true、**埋雷本体** `3129` 不传；回旋镖风痕 DoT `1518` 传 true、同塔风暴镖 `3223` 不传 —— 同一技能体系内两种口径，说明是漏而非设计。

### 2.4 预期规则（候选）

| 方案 | 规则 | 改动面 | 玩家感知 | 评价 |
|---|---|---|---|---|
| **A（推荐）** | 按 2.2 分类收口，17 处补 `true`，6 处保持 | 17 行 + 口径注释 + 1 个静态扫描测试 | 冰/电/毒/炮/回旋的技能在充能3★ 下有提升 | 与现有代码注释自洽，可枚举、可断言 |
| B | 全部吃（`isSkill` 默认 true，普攻主路径显式 false） | 改默认值 + 全站回归 | 近似 A，但碎冰/火焰弹射/散射火球也被顺带加强 | 改动最少，但把「普攻强化」划进技能，口径更糊 |
| C | 废布尔参数，改 `shotDmg(key, 'skill' \| 'attack')` 枚举 | 57 处签名 | 无 | 最干净，属重构，并入后续战斗层重构，不在本轮 |

### 2.5 调整前后影响

**公式**：`塔伤提升 = 技能伤占比 × (1 + i)`，`i = chargeSkillBoost/100`，上限 `i = 0.5`。

**受影响技能的理论秒伤贡献**（÷ 该塔 dps；无分支、全命中的上界值）

| 塔 | 技能 | 周期 / 系数 | 贡献 |
|---|---|---|---|
| 冰 | 冰花 0.8 / 8s | — | 0.11 |
| 冰 | 冬珠 0.44 × 6 跳 / 10s | — | 0.29 |
| 电 | 雷暴 0.64 × 3 目标 / 10s | — | 0.19 |
| 电 | 极光电击 0.8 × 2 目标 / 8s | — | 0.20 |
| 毒 | 毒池 0.20/s × 4s / 5s | — | 0.16 |
| 毒 | 毒棒 0.24/s × 10s / 10s | — | 0.24 |
| 炮 | 炮火支援 0.60 × 3 目标 / 12s | ×1.8 间隔 | 0.27 |
| 炮 | 炮台 0.68 / 0.9s（8s 存续） | ×1.8 间隔 | ≈1.0（受命中率折损，存疑，须实测） |
| 回旋镖 | 弹力镖 0.60 × 2 枚 / 8s | ×1.3 间隔 | 0.20 |

**量级结论**：改后单塔 DPS 上限提升约 **+8% ~ +25%**（i=50% 满层），**炮塔最高、冰塔最低**；且只在「拿到全局充能3★ 且反复溢出堆满」这条稀缺路径上体现，属**上限抬升**而非平均抬升。基础 6 塔数值与关卡曲线不用动。
