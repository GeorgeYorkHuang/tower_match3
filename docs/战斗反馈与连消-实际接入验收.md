# W战斗反馈与连消：实际接入验收

本批为玩法/表现接入，独立于默认行为等价拆分。保留W原模块，修正接线契约中的示例路径/上下文与充能、彩虹元数据问题。

## 已接入行为

### 血条与数字

怪物（含精英/Boss）默认不画血条，保留城墙防线、debuff、Enemy hp/maxHp/delayHp与击杀/掉落。配置enemyBars.show可恢复。

每局独立DamageNumbers实例。damage扣血后、死亡递归回调前经combat-feedback适配器发正的实际损血事件；护甲/易伤后取值，过量伤害不显示超过剩余血量，零/负数不生成“1”假伤害。DoT标记用于合并；腐化真伤补独立入口。缺来源的旧灼烧按类型提供显示色，不改原伤害来源/击杀归属。未知来源用中性色。

数字在普通/测试战场的敌人与特效层之后、弹层之前绘制；受战斗倍速影响，暂停不推进；禁用或来源筛选只影响表现。退出/结束/重开清数字与在飞弹道，不能跨局残留。

### 连消攻击

Run.trySwap仍逐级执行原applyMatch/_blastReward；每步结算后按当时slotOrder构建计划，考虑刚获得的塔。捕获chainstorm再消费，保留配置阈值（默认4组、连锁风暴2组），不靠隐藏旧chain槽位决定新攻击。

实际clear记录覆盖三连、四/五消和爆炸波及，同一步同格去重；不同步骤出现新块可再发。按实际棋盘布局计算出发点，元数据不从最终下落棋盘猜颜色。

Match3在每级clear开始时发射，一步只执行一次；交换/消除规划阶段不提前出伤，弹道沿用Combat公共命中路径。替换旧spawnChainShots同步调用/随机周期奖励，基础消除经验和充能不改。

**保留的边界**：未出战颜色不生成猜测塔弹，沿用原三连匹配组的额外充能回退（不是每格再加5点）；特殊/爆炸自身的正常充能已由原结算完成。彩虹自身默认不发真实攻击，有色的普通清除格照常发弹。通用无色表现弹尚未接入。这些与W的第一阶段策略一致。

暂停时动画与弹道冻结，结束/退出/重开取消动画、在飞/延迟队列；动画重入不重复发射。

## 改动入口

- main：每局数字实例、更新/绘制、棋盘布局注入、暂停与生命周期清理。
- render：怪物血条开关、数字绘制、测试场层级。
- combat/damage与statuses：实际损血事件、DoT显示上下文和腐化真伤。
- run：逐步弹道计划与仅保留旧inactive三连充能回退。
- match3：clear阶段一次性发射、暂停冻结。
- board/chain-attacks：标记真正的彩虹格；不把整组有色格误当无色。旧未标记快照仍兼容原模块回退。

四个HTML构建器加入combat-presentation依赖，三个预览重建。

## 用户测试清单

1. 普通/精英/Boss血条隐藏，城墙血条仍在；六塔打怪数字颜色正确，毒/火持续伤害有数字。
2. 达到连消阈值后，四消/五消/爆炸波及格也随对应级次飞出弹道，命中才扣血；经验、充能正常，无旧连消攻击叠加。
3. 打开暂停/三选一后弹道与数字冻结；恢复后继续，返回主页/重开不残留。
4. 密集连消真机观察流畅度与数字可读性；必要时只调表现上限/合并参数，不丢真实伤害。
