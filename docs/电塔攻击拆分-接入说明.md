# R15第九批：电塔攻击与命中拆分

## 接口与接入

新增`js/combat/towers/electric.js`，仅持有共享tower-skills定义，实例上下文每次显式传入：

- hitElectric(combat, enemy, damage)：主目标、过载、电涌、活电电球生成、连锁伤害和冷却返还。
- tryAttackDebuff(combat, enemy, damage)：原统一tryAttackDebuff中electric分支，负责麻痹、强麻门控和导电传播。
- onAnyTowerHit(combat, enemy)：原统一hit开头的电磁场，所有六塔仍可触发，不缩窄成电塔专属。

Combat.hitElectric保留同名委托；统一tryAttackDebuff只在electric分支委托；统一hit先调用onAnyTowerHit，再分派各塔自身命中，之后才更新命中计数/通用特效。没有新增第二次伤害或递归hit入口。

## 保持原行为

- _ovDbl先消费，再结算主伤；过载在旧麻痹状态下叠层，C爆发先于A清层/返能；反复击打的标记与层数不调整。
- 电涌、强麻、导电链与磁力分叉继续按原条件/顺序消耗随机数。
- 活电保持原等分初角/抖动/随机速度和orb.fx/ref引用关系；本批只迁生成段，stepShot中的移动碰撞仍在通用调度。
- 连锁按最近未命中活目标选择，衰减、超导/传导/电弧/电光/电链增强规则与返冷却封底不变。
- 麻痹传播原本只排除上一跳、没有完整去重集合，当前行为保留，不借拆分改链路。
- 主attackOnce中的充能/快充攻击计数、周期tickElectric、六塔调度与公共伤害/状态留原处。不调整P2/P3和技能数值。

所有电球、能量、层数、计时、敌人状态均归当前Combat/Run/Enemy；模块不缓存玩家，也不改配置。

## 验证

`tools/_test_electric_attacks_split.cjs`固定读取7a3bb51旧Combat：

- 1280组：10种技能组合、分支0~3、圣遗物0~3★、两组随机种子，覆盖hitElectric、统一debuff、统一hit和真实attackOnce；推进初始和新增电球，比较所有实例状态、副作用、弹道/表现与随机调用次数。
- 24组：六塔分别触发电磁场、有无其他活目标、不同随机种子，防止迁移后丢失跨塔挂点。
- 额外断言：过载C先爆发后A清层、返能封顶、连锁不重复选同一敌人、返冷却不为负、强麻失败分支与双实例隔离。

回归通过：火塔攻击1024组、冰塔攻击1024组/周期256组、公共伤害882组/状态432组/弹道456组、火冰多弹道、圣遗物击杀1370组和波次554组。

本批未改UI/资源，也未合入工作区W新交付的combat-presentation、damage-numbers、chain-attacks等独立文件；后续单独验收接线。新模块不由Renderer引用，无需新增HTML预览内联。
