# 伊格尼斯 W60 首版接入

熔岩矿场 W60 已注册 `lava_ignis`，遭遇标记 final，击败沿用现有终局结算入口。首版生命183000、护甲45%、冻结/击退免疫、路径80%对峙；生命按当前薇拉预算同比折算，尚未完成数值平衡。

## 行为

- P1 升温：每12秒全塔攻击间隔×1.25，持续4秒。
- P2 抛核（70%）：追加阶段怪，并每15秒排入5只熔核。熔核生命1280，活体加待出场合计上限10只，避免长帧或堵塞时无限排队。
- P3 过载（35%）：保留过热/抛核；开始8秒自爆读条。读条期间实际损失累计达到最大生命5%时打断，8秒后重新开始一轮读条。不足则城墙损失最大生命25%，随后再次蓄压。
- 熔核规则收敛为到墙自爆1%城墙最大生命一次；提前击杀不扣墙。旧稿“死亡扣墙”和“提前击杀避免扣墙”互相矛盾，以此实现保证反制有效。
- 到墙自爆走实体死亡清理，不作为塔伤害入账；沿用现有死亡钩子。自爆与Boss爆发伤害尊重复活保护，城墙降至0时标记失败。
- 阶段追加怪使用熔岩战场定义生成，预算与出生读取同源配置。动态熔核加入遭遇总血记账。

## 表现及限制

新增简版血条、阶段刻度、过热提示、过载剩余秒数和打断伤害进度。Boss本体与熔核仍使用占位，正式美术未接入。读条按遭遇战斗时钟计算，不使用墙钟。
