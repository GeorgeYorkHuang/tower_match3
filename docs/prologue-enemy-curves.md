# 前两章独立怪物成长初版

日期：2026-11-11。保留第一章Lv1、第二章最高Lv4及九次技能激活；没有增加隐藏攻击乘区、技能分支或经验补偿。

## 曲线

血量为最终出生值，不再叠乘正式代际血量和原先的章血量折扣。

| 类型 | 第一章 W1→W10 | 第二章 W1→W15（W16–20持平） |
|---|---:|---:|
| 普通 | 110→150 | 130→280 |
| 快速 | 70→100 | 85→180 |
| 坦克 | 220→280 | 260→600 |
| 精英 | 配置300→360，但本章精英上限仍为0 | 350→700 |
| 小Boss | 700→1100，仅5/10波实际出现 | 1000→1800，仅5/10/15波实际出现 |
| 护甲 | 0→4% | 0→8% |

第一章每四个普通投放位安排一只快速怪，第4波起每十个安排一只坦克；第二章分别为每四个/每七个。怪物类型不再跟随正式关卡的代际跳变。

数量仍保留原55%/65%波次数量规则；精英上限、城墙生命、怪物攻城/移速倍率不改。第二章第15波之后不再上涨单怪生命与护甲，但投放数量仍可缓慢增加。

第二章W20萝赛独立覆盖为：9000生命、8%护甲、400护盾/18秒。保留转阶段、召唤等机制；护盾和生命不改写正式Boss配置。两阶段随从及召唤物使用本章对应类型血量，避免Boss本体减弱而随从仍套正式关卡血量。

第三章与正式战场继续使用原有成长规则和Boss数值。

## 接线

- 配置：`js/config/prologue.js`的 `enemyCurve` 与第二章 `bossProfile.overrides`。
- 纯计算：`js/prologue/enemy-curve.js`，按章内波次线性插值/平台化。
- 出生：`js/prologue/balance.js`，最终血量与护甲只应用一次。
- 投放与预算：`js/wave.js`，前两章使用独立类型配比；出生总血量和普通波预算同源。
- 波末口径：`js/run.js`读取当局波次预算，避免用正式总血量计算前置章的抽象压力。
- 萝赛随从：`js/bosses/rosea.js`的entry读取章节血量；脚本Boss本体继续由配置覆盖生成。
