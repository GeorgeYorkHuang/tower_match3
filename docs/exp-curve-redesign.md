# 经验双曲线重配：通关 35 级 / 满级 48 级留给深渊

> **交付类型**：数值设计草稿（理论推演数据），不含代码改动。
> **口径**：全歼、无经验加持圣遗物、普通战场 W60 通关 / 深渊裂隙 W1–90。
> **所有数值为理论推演，标注「待原型验证」，落地前需以实机埋点复核。**

---

## 0. 核心结论

**只改一条曲线做不到，必须两条同时改，且它们由一个硬等式锁死：**

```
E(48) / E(35)  =  Cum(90) / Cum(60)          ← 配平恒等式
（累计升级需求）   （累计经验供给）
```

| 曲线 | 现状 | 新方案 |
|---|---|---|
| 经验需求 `expNeed(L)` | `35 × 1.25^L`（单段指数） | **三段连续曲线**，L0–9 / L10–34 / L35–47 |
| 怪物经验 `killExp` | 固定表，不随波次变 | **`killBase × (1 + 0.045×(w−1))`**，逐波线性放大 |

配平结果：**W10 = 10 级、W60 通关 = 35 级、深渊 W90 = 48 级（硬上限）**。48 级在普通战场无论如何打不到。

---

## 1. 为什么必须两条一起改

| 做法 | 结果 |
|---|---|
| 只降需求曲线 | 需求降约 16 倍可让 W60 到 35 级，但击杀经验固定 → 深渊 30 波给不出 2.8 倍累计经验 → 48 级仍不可达 |
| 只涨怪物经验 | 供给涨约 10 倍可让 W60 到 35 级，但 `1.25^L` 后期每级需求 6 万+ → 深渊 30 波照样不够 |
| **两条同改** | 让 `Cum(90)/Cum(60)` 与 `E(48)/E(35)` 对齐在 **2.80**，两个目标同时成立 |

**现状基线**（上一轮 `docs/balance-analysis.md` 实测，20 局均值）：W60 仅 **20.2 级**，每波经验供给 61–400，升一级需 **52.6 波**；`E(48) = 35×(1.25^48−1)/0.25 ≈ 627 万`，是 60 波总供给的约 400 倍，理论满配完全不可达。新方案把 `E(48)` 压到 **40.2 万**，同时把 60 波累计供给从约 1.5 万提到 **14.3 万**。

## 2. 新曲线公式与可直接落配置的参数

### 2.1 怪物经验提供曲线（供给）

```
每波经验 S(w) = 三消 41.75 + 波末 20 + killPool(w) × (1 + 0.045×(w−1))
```

- 三消：`floor(2 × 块数 × 形状倍率)` × 5 次/波，按 `matchDist` 期望 = **41.75**
- 波末：`EXP.waveBonus(5) × TOWER_SLOTS(4)` = **20**（前期塔未满 4 座时实际略低，属保守估计）
- `killPool(w)`：当前 `EXP.kill` 固定表按本波怪物构成求和；W1–60 取已精算值（脚本 Boss 波按实际投放），W61–90 同规则外推
- **新增缩放 `α = 0.045`**：击杀经验逐波 +4.5% 线性，让供给随进度增长，而不是靠怪物数量被动增长

`EXP.kill` 基础表建议保持 `{normal:15, runner:10, tank:22, elite:30, boss:90}`，只在外层乘波次系数，改动面最小。

### 2.2 经验成长曲线（需求，三段连续）

```
L  0– 9 : need(L) = 140.7   × 1.2500^L
L 10–34 : need(L) = 1047.9  × 1.1126^(L−9)
L 35–47 : need(L) = 15095.9 × 1.0384^(L−34)
```

| 锚点 | 本级需求 | 累计 E(L) |
|---:|---:|---:|
| L0 | 141 | 0 |
| L9 | 1,048 | 3,629 |
| L10 | 1,166 | 4,677 |
| L34 | 15,096 | 128,383 |
| **L35** | 15,676 | **143,479** |
| L47 | 24,646 | 376,909 |
| **L48** | —（硬上限） | **401,555** |

三个参数由三个约束反解：`E(10)=Cum(10)=4,677`（前期手感）、`E(35)=Cum(60)=143,479`（通关）、`E(48)=Cum(90)=401,555`（深渊满级）。段间自动连续。

> **单一指数做不到的原因**：想让 L0 需求低（前期快升），`base` 就得小 → 为凑够 E(35) 必须把 `g` 抬到 1.18 以上 → `E(48)/E(35)` 会变成 9 倍以上，48 级被推到深渊 200 波后。三段曲线是同时满足「前期爽感 + 通关 35 + 深渊 48」的最小改动结构。

## 4. 关键验证

### 4.1 「48 级只在深渊」是否守得住

普通战场 W60 就 `finalVictory` 结束，累计经验锁死 143,479 < E(48) 401,555，**天然到不了 48**。

带经验圣遗物时（把击杀加成、`cm_tome` 需求减免、经验珠补差统一折算成总经验倍率）：

| 等效加成 | W60 等级 | W90 等级 | 是否守住 |
|---:|---:|---:|---|
| +0%（本方案基准） | **35** | 48 | 是 |
| +20% | 36 | 48 | 是 |
| +30% | 37 | 48 | 是 |
| +50% | 39 | 48 | 是 |
| +100% | 42 | 48 | 是 |
| **+180%** | **48** | 48 | **否（破线）** |

即：**只要全来源经验加成总等效不超过 +180%，48 级就只可能在深渊达成**。现有单个圣遗物加成远低于此，余量充足；但若后续叠加经验珠、连锁、天赋等多来源，需重算总等效倍率。

### 4.2 α 敏感性（可调旋钮）

| α | Cum(60) | Cum(90) | R | 段 B 增速 | 段 C 增速 | 破线所需加成 |
|---:|---:|---:|---:|---:|---:|---:|
| 0.030 | 114,288 | 306,278 | 2.68 | 1.1016 | 1.0397 | +168% |
| **0.045** | **143,479** | **401,555** | **2.80** | **1.1126** | **1.0384** | **+180%** |
| 0.060 | 172,670 | 496,831 | 2.88 | 1.1209 | 1.0367 | +188% |
| 0.080 | 211,591 | 623,866 | 2.95 | 1.1294 | 1.0344 | +195% |

四档都能达成两个目标，只是数值量级不同。`α` 主要调「后期每波经验的绝对值」，对段 C 增速几乎无影响（1.034–1.040），因为供给与需求同比例放大。推荐 **0.045** 作为中值。

## 5. 前提、风险与待确认

| # | 项 | 说明 |
|---|---|---|
| 1 | **全歼是最大前提** | 本表假设击杀经验 100% 入账。代码里击杀经验走 `onKill` 才给（`js/relics/kill-hooks.js:116`），一旦漏怪就少拿经验，会复现上一轮报告里的「打不过→少经验→更打不过」正反馈。建议下一轮评估「击杀经验按投放量保底结算」，但这属于工程改动，未计入本表参数 |
| 2 | 深渊按 W90 锚定 | `settlement.js:92` 深渊进度条 `waveMax=90`，但 `WAVE.maxWave=9999` 实际可无限打；W90 是「结算展示上限」，不是硬终点 |
| 3 | 深渊是独立一局 | `finalVictory` → `finishRun(true)` 结束，深渊从 W1 重开、前 60 波与普通战场同曲线，W61 起才继续涨。需确认没有跨局经验继承 |
| 4 | 段 C 增速偏低 | 1.0384 使 L45→L48 仅 5 波（1.7 波/级），满级冲刺偏快。想拉长得改约束（把满级锚点推到 W100+）或单独给段 C 加增速，但会破坏 W90=48 的等式，需产品先定「满级该有多难」 |
| 5 | 数值量级放大 | W90 每波 13,906、need(47) 24,646，比现状大 10–40 倍；经验条 / 数字显示 / 存档字段需确认能承载 |
| 6 | Boss 波节奏坑 | W20/40/60 击杀池明显低于相邻波，Boss 波升级会变慢；若体感突兀，可给 Boss 波单独补一份击杀经验 |
| 7 | 深渊全歼难度 | 每 10 波诅咒 ×1.15 血量，W90 约 3.5 倍，叠加怪物等级表；48 级是「理论可达成」，不是「稳定达成」 |
| 8 | 静态口径 | 三消按 5 次/波期望、波末按 4 塔满编；实际连锁、惩罚色、塔未集齐会造成波动，需实机埋点校准 |
| 9 | 参数联动 | 通关波次、深渊波次、经验入账链路任一变动，三个约束必须重解，不能直接改单个常量 |

**下一步需产品/工程确认的 3 个口径**：① 满级锚点是 W90 还是要更晚；② 击杀经验是否改保底结算；③ 是否允许经验圣遗物让普通战场到 38–40 级（本方案 +50% 时是 39 级）。
