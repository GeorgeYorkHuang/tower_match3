# 六塔攻击配置调整：移除共用结算增伤

## 实际修改

- 删除共用伤害倍率及其结算代码，不保留隐藏乘区。
- 六塔`baseDps`和`perLv`直接增加20%，1–13级基础攻击曲线同比提高。配置保存在`js/config/towers.js`；原字段以DPS存储，单次攻击=该DPS×基础攻击间隔。
