# 局内圣遗物方案B：已接入规则

更新日期：2026-11-10。适用圣坛花园、熔岩矿场、霜风峡谷；深渊保留原精英与Boss掉落节奏，后续单独设计。测试战场不发战斗奖励。

## 发放节点

| 波次 | 奖励 |
| --- | --- |
| 进入W2 | 首次普通局内宝箱，必给一次 |
| 击败W5、10、15、25、30、35、45、50、55的Boss | 每波必给一个普通局内宝箱 |
| 击败W20、40的Boss | 每波必给一个金色局内宝箱，所有候选均为SSR |
| W56–59 | 不新增局内宝箱 |
| W60 | 不新增局内宝箱；Boss局外宝箱、普通碎片及5–10片红卡碎片沿用原奖励 |

基础合计12个局内宝箱，其中2个为全金；十波分段为3、2、2、2、2、1个。此数是发放机会：玩家仍需在棋盘消除宝箱邻格并从候选中选择，未领取的早期宝箱可以留到后续波次领取。

普通三地图精英不再随机掉局内宝箱，其经验、银币和碎片保留。历练三星的开局额外三选一、天赋中央自选均独立于这12个节点；两种额外来源都生效时最多多2件。

## 品质与去重

- 普通宝箱沿用蓝50%、紫38%、金12%的逐候选品质权重，以及候选不重复、本局紫/金不重复、蓝卡可叠加规则；品质池不足时仍有原来的补位行为。
- W20/40的宝箱以`rarity: 'ssr'`携带全金限制；掉落、飞入棋盘、棋盘格、开箱队列、展示前重新筛选、付费重掷及点击时校验均保留该限制。
- 金色候选优先来自在场塔及通用池。只剩1或2张时就展示剩余数量，不以低品质补位；该池全部用尽后才从其他塔系尚未获得的SSR中补选。
- 若所有塔系及通用SSR均已获得，金色宝箱补偿500局内银币并提示，不降级、不重复发金卡。补偿值可配置；重掷无候选时不扣款。
- Boss奖励按敌人的归属波次去重，不按当前显示波次。双生Boss第一尊死亡不发，最后一尊死亡发一份；Boss局外宝箱和碎片也不因多单位重复发放。
- 开新局时清空去重标记。红卡碎片仍由原终极Boss逻辑记录、局末统一入账。

## 宝箱·寻踪

继续使用原ID与星级，改为圣遗物三选一重掷费用降低15%／25%／35%；三星保留候选品质提升1档（蓝→紫、紫→金、金不变）。

优惠只作用于圣遗物重掷，技能升级重掷原价不变；两者仍共享重掷次数。圣遗物界面显示的价格与实际扣费使用同一接口，按整数银币四舍五入。例如第一次原价500，三种星级分别425／375／325银币。
