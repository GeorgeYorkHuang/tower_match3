## 用户集中验收（微信开发者工具或手机）

| 场景 | 需要观察 |
| --- | --- |
| 熔岩40 | 名称正确；60%分成两个目标；第一体死不解锁，第二体死后继续；三层共鸣后护甲不再增长 |
| 霜风40 | 分裂时全敌短时加速，4秒后恢复；两体编号清楚；同步倒计时和奖励提示各出现一次 |
| 熔岩60 | 70%开始投核；提前击杀熔核不扣墙、触墙自爆只扣一次；35%出现8秒读条；打断进度满后停止读条，等待8秒重启 |
| 霜风60 | 70%和40%各一次霜影；35%后两塔先预警1秒再冻结4秒；冻结时新攻击停、已有弹道仍命中，结束后恢复 |
| 暂停/倍速 | 打开三选一或暂停后预警/读条停止；恢复继续；4倍速与实际伤害时机一致 |
| 复活/退出 | 死亡复活Boss不重置、不重复刷阶段怪；回主页再开局无残留冰封/过热 |
| 终局 | 两张地图W60击败Boss后只结算一次，记录对应地图通关 |
