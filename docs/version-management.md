# 发布版本管理

当前最新上传版本：**V1.18.5**（项目维护者确认）。

## 唯一入口

`js/config/version.js` 导出 `version`（1.18.5）和 `display`（V1.18.5）。后续发布只修改这里的 version；主界面“信息”通过主流程读取 display，禁止在业务文件新增硬编码游戏版本。

微信开发者工具上传窗口的版本号需要填写相同值；配置文件本身不能修改微信后台已上传版本。

## 本次梳理

原入口位于 js/game/main.js，硬编码 v1.17.23，已经落后于上传版本。现改为引用统一配置。清理了 1217 个历史注释版本标签，包括 v5.6.8 这类与当前发布编号冲突的标记；保留原功能说明。注释清理经过语法树对比，确认不改变执行逻辑。修改时间与历史版本应查 Git 提交记录，不再用散落的版本注释维护变更历史。

## 独立版本仍保留

- save.js 的整数版本用于识别、迁移存档，存储键后缀同样保持，避免旧存档丢失。
- project.config.json 的 libVersion 是微信基础库版本，不是游戏版本。
- 文件名和资源路径中的 v1/v2 等用于区别素材批次，不能批量重命名。
- combat-presentation.js 的 version: v1 是表现配置结构标识。
- 第三方文件的版本与许可证不属于游戏发布编号。

## 发布操作

1. 更新 js/config/version.js 的 version。
2. 打开主页功能菜单中的“信息”，确认显示的发布版本。
3. 微信开发者工具上传窗口填写相同版本号并说明变更。

本次保留全部存档版本、资源路径和基础库设置。
