# 紫卡槽位置与两系列档位分布（2026-11-22 修订版）

> 本文取代 `purple-cap-and-gale-cards-spec-2026-11-22.md` 第 1.1b 节的"4 双 + 1 只紫 + 1 只金"，改为 **熔铸 4/2/0、霜风 2/2/2**，并给出"中间紫卡槽"的坐标与形状改法。
> 紫名额 1/2/2、按 `nativeSlot` 升序取前 N、易伤加算、`_thawImmune` 等规则不变。

## 1 先纠正一个前提：中间紫卡槽现在够不到

天赋盘 90 格的实际构成（`config/talents.js` 实读）：

| 类型 | 数量 | 说明 |
|---|---|---|
| green | 36 | 绿点（攻速/伤害/技能/持续/dot/充能） |
| white | 36 | 白点（固定塔攻击 +2） |
| **purple** | **12** | 紫点，分两层 |
| slot | 6 | 六个扇区中心 |

12 个紫点的分布：

- **外圈 6 个**（半径 2~4）：`-4,2` `-2,-2` `2,-4` `4,-2` `2,2` `-2,4` —— 正是圣庭 6 张卡的默认紫点，一塔一个。
- **内圈 6 个**（半径 1）：`-1,0` `-1,1` `0,-1` `0,1` `1,-1` `1,0` —— **目前没有任何一张卡能覆盖**。

用 `model.js` 的 `footprint` 复算了 18 张卡在各自槽位的结果：

| 星 | 外圈默认紫点 | 内圈紫点 |
|---|---|---|
| 1★（4 格） | 不覆盖 | 不覆盖 |
| 2★（8 格） | 覆盖 | 不覆盖 |
| 3★（12 格） | 覆盖 | 不覆盖 |

原因很简单：每张卡的中心在半径 3 的外圈（`rotate(0,-3,slot)`），形状向外长，最内只到 dist 1~2，够不到盘心。

**所以"把紫卡槽放到中间"不是改一个坐标，必须同时给那张卡的 2★/3★ 形状加一格"内伸格"，代价是少一个绿/白属性格。** 下面就是把这一格加在哪、加给谁。

## 2 档位分布（4/2/0 与 2/2/2）

### 2.1 熔铸：4 双 + 2 只紫 + 0 只金

| 卡 | 档 | 紫 | 金 |
|---|---|---|---|
| 炽核熔炉（火） | 双 | 熔渣灼甲（护甲 ≥30%，+12%） | 破甲熔穿 |
| 膛压炉心（炮） | 双 | 膛压贯甲（弹药 ≤40%，+12%） | 回火装填 |
| 淬火槽（冰） | 双 | 冷淬崩甲（减速中，+12%） | 淬裂生纹 |
| 硫磺脉（毒） | 双 | 硫脉蚀甲（带 dot，+12%） | 硫毒穿甲 |
| 电弧熔渣（电） | **只紫** | 熔渣导弧（带熔穿，+12%） | — |
| 矿渣回旋（回旋） | **只紫** | 矿渣旋切（护甲 ≥15%，+12%） | — |

- 紫池 6 张全亮 → 名额 2/6，竞争最紧；金池 4 张（实际局内最多 4 塔，正好够用）。
- 自洽：电紫吃熔穿（火金提供）✓；回旋紫吃护甲 ≥15%（熔岩全场护甲 ≥20%）✓；两者都不依赖已砍掉的金。
- 代价：熔铸没有回旋金了，"穿透护甲的黑科技"没了，破甲只剩熔穿（−10 点）+ 火金当次无视 50%。熔岩 W60 满熔壳 54% → 熔穿后 44%，火金命中瞬间 17%。

### 2.2 霜风：2 双 + 2 只紫 + 2 只金

| 卡 | 档 | 紫 | 金 |
|---|---|---|---|
| 凝霜之心（冰） | 双 | 霜心凝滞（冻结中，+12%） | 霜心领域 |
| 融霜火线（火） | 双 | 融霜余烬（解冻后 2 秒内，+12%） | 融霜爆裂 |
| 霜蚀孢子（毒） | **只紫** | 霜蚀渗透（减速 ≥25%，+12%） | — |
| 静电风眼（电） | **只紫** | 静电风眼（**带风痕**，+12%） | — |
| 逆风回响（回旋） | **只金** | — | 逆风刻痕（挂风痕） |
| 霜炮轰鸣（炮） | **只金** | — | 霜炮轰鸣（减速 + 半径） |

**这套是唯一能保住"风痕 → 冻结 → 解冻"完整链的分法**，逐条验：

- 风痕来源 = 回旋金「逆风刻痕」✓（所以回旋不能只紫）
- 冻结来源 = 冰金「霜心领域」，其"带风痕才冻"的前置成立 ✓（所以冰不能只紫）
- 解冻 + 2 倍 = 火金「融霜爆裂」✓，且火紫「解冻后 2 秒 +12%」需要火金设 `_thawTtl`，所以火必须双 ✓
- 电只紫 → 没有电金 → **没有麻痹来源**，因此电紫条件从"麻痹中"改为"**带风痕**"（风痕由回旋金提供）✓
- 毒只紫 → 减速 ≥25% 由冰金 35% / 炮金 30% 提供 ✓
- 炮只金 → 减速来源保留（毒紫依赖它），但炮紫"一次炸 ≥3 只"下线 ✓

紫池 4 张（冰/火/毒/电），名额 2/4；金池 4 张（冰/火/回旋/炮），实际 4 塔全可用。

## 3 中间紫卡槽：坐标 `0,1`，给两个系列的电卡

### 3.1 为什么是 `0,1`

内圈 6 个紫点里，离"电卡形状"最近的只有它：

| 候选紫点 | 距电卡（slot3，中心 0,3） | 需要的格数 |
|---|---|---|
| **`0,1`** | 2 步（`0,2` 已覆盖，再进 1 格） | **1 格** |
| `1,0` / `0,-1` | 3 步 | 2 格 |
| `-1,1` | 2 步但在另一侧，需绕行 | 2 格 |
| `-1,0` | 3 步 | 2 格 |

其他卡的形状最内只到 dist 1，且都是绿/白点（例如毒卡最内 `-1,-1` 是 white/fire），换到内圈紫点至少 2 格，代价更大。所以**只有电卡（slot3）能用 1 格换到盘心紫点**。

### 3.2 改法（熔铸电、霜风电同一几何，改动一致；属性零损失）

电卡现状（slot3，中心 `0,3`）的**原始 shape 偏移**（`shapeRotation` 未设，按 `nativeSlot=3` 旋转三圈，等价于取反号）：

- s1（4）：`-1,0` `0,-1` `-1,1` `-1,2`
- s2（8）：`-1,0` `0,-1` `-1,1` `-1,2` `1,0` `-1,-1` `-2,1` **`1,-1`**
- s3（12）：s2 的 8 格 + `1,1` `-2,0` `0,1` `1,-2`

落到盘面上的绝对格：

- s1：`1,3` `0,4` `1,2` `1,1`
- s2：`1,3` `0,4` `1,2` `1,1` `-1,3` `1,4` **`2,2`(紫)** `-1,4`

**唯一改动：把 s2 / s3 里的原始偏移 `-2,1` 换成 `0,2`。**

- `-2,1` 落到盘面是 `2,2` —— 那是电卡的**默认外圈紫点**，紫点改到盘心后它就是一格废格；
- `0,2` 落到盘面是 **`0,1`（内圈紫点）**；
- 置换后 s2 覆盖 = `1,3`(white) `0,4`(green) `1,2`(green) `1,1`(white) `-1,3`(green) `1,4`(white) `-1,4`(white) + `0,1`(紫)。
- **7 个绿/白格一个不少**（原来那 7 个本来就都在，只是把无用的紫点格换成了有用的紫点格），属性零损失。

改后结果：

| 星 | 覆盖 `0,1` | 是否出紫 |
|---|---|---|
| 1★（4 格，不含 `0,1`） | 否 | 否 |
| 2★（8 格） | 是 | 是 |
| 3★（12 格） | 是 | 是 |

配套：
- `purpleNode` 从 `2,2` 改为 `0,1`；
- `config/talents.js` 的紫点坐标表不用加节点，`0,1` 已经是现成的 purple 节点；
- 只改 `red-series.js` 里生成 `ur_forge_electric` / `ur_gale_electric` 时对 `shape` 的替换，**不动圣庭电卡**（圣庭继续用外圈 `2,2`）。

### 3.3 备选：如果不想动形状

那就只能让这两张卡继续用**默认外圈紫点**（电 `2,2`），"中间紫卡槽"留空。机制上完全等价（紫点只认 `purpleNode` 一个坐标），区别只有视觉：盘心紫点一眼就是"核心卡"，外圈紫点混在六张卡里不显眼。建议按 3.2 改。

## 4 12 个紫点最终归属

| 紫点 | 半径 | 归属 |
|---|---|---|
| `-2,-2` | 外 | 圣庭·火（默认） |
| `2,-4` | 外 | 圣庭·炮（默认） |
| `4,-2` | 外 | 圣庭·回旋（默认） |
| `2,2` | 外 | 圣庭·电（默认）；熔铸/霜风电改走 `0,1` 后此点空置 |
| `-2,4` | 外 | 圣庭·冰（默认） |
| `-4,2` | 外 | 圣庭·毒（默认） |
| **`0,1`** | 内 | **熔铸·电、霜风·电（中间紫卡槽）** |
| `-1,0` | 内 | 空置（预留） |
| `-1,1` | 内 | 空置（预留） |
| `0,-1` | 内 | 空置（预留） |
| `1,-1` | 内 | 空置（预留） |
| `1,0` | 内 | 空置（预留） |

> 两个系列共用 `0,1` 不冲突：它们不在同一战场、也不在同一局（系列由战场决定），紫点判定的 `sources` 是"本局装配的卡"聚合，不会跨系列串。

## 5 同步影响

1. **熔铸紫池变成 6 张**（4 双 + 2 只紫），名额 2/6。上一版"4 双 + 1 只紫 + 1 只金"作废：回旋紫恢复生效（护甲 ≥15% +12%），电金「熔流分叉」保持作废。
2. **霜风紫池 4 张、金池 4 张**，名额 2/4。霜风的电金「风眼雷涌」作废（麻痹链断），毒金随"毒只紫"一并作废；回旋金、炮金、冰金、火金保留。
3. **只金卡（霜风回旋/炮）2★ 无紫无金** → 装配面板要标"2★ 无效果，建议 3★"，且这类卡排在后面。
4. **只紫卡 3★ 只扩覆盖** → 卡面必须写"3★：仅扩大覆盖，无金效果"。
5. 图鉴/盘面渲染要支持"非默认紫点"（现在紫点是卡上的固定坐标，按 `footprint` 算出来；只要配置改对了，渲染不用改逻辑，但要确认 UI 不是按 `nativeSlot` 硬画外圈）。
