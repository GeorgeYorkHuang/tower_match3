## 二、实现要点（动工时给 Codex 的接口）

```js
// render.js menuBattle 内（约 4282 行）
this._menuSkillCards(ctx, s, push, '三消技能', s.matchSkills, 55, 970, 640, 200, true);
this._menuSkillCards(ctx, s, push, '全局技能', s.globalSkills, 55, 1234, 640, 200, false, { cardDX: 84 });
```

`skill-loadout.js` 的 `skillCards` 需加第 11 参（或 opts）`cardDX`：**只移卡片不移标签**——

```js
const left = x + 90 + (opts && opts.cardDX || 0);   // 原 const left = x + 90
```

竖排标签 `x + 30` 保持不变（两行标签列对齐在 85）。若整体平移 x（改传 x=139），标签会跟到 169、与三消行错位，**不要这样做**。

## 三、影响面与风险

- 仅主页战斗页两行技能卡；配置面板（matchCfg/globalCfg）坐标全部由面板自己算，**不受影响**；
- 命中区随卡片走（push 用同一坐标），main.js 分发零改动；
- 行2 底 1434 与光束起点相接属「相切不重叠」，斜纹审计已确认 0 面积；
- 唯一代价是按钮→行1 间距 43→23（19px 标签距按钮 23px）。若真机观感偏挤，回退方案：按钮 y 850→840（战场卡→按钮间距 58→48，仍 >40）。
