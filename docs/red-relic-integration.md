# 圣庭红卡统一接入

唯一有效红卡为天赋配置中的六张圣庭卡。图鉴、猩红宝箱、地图说明及通关 Boss 使用同一份卡表与来源映射，普通随机池不混入红卡。

| 地图 | 通关Boss掉落池 |
| --- | --- |
| 圣坛花园 | 圣庭·烬火圣印、圣庭·蚀生之种 |
| 熔岩矿场 | 圣庭·轰鸣核心、圣庭·雷脉棱晶 |
| 霜风峡谷 | 圣庭·霜心圣晶、圣庭·回风徽记 |

60波 Boss 击杀保底获得池内随机一张卡的5～10片，每局同一 Boss 奖励只记录一次；支持花园专用 Boss 及另两个地图的通用60波 Boss。进入局内碎片账本，沿用结算与碎片双倍规则；测试和深渊不额外发放本项掉落，20／40波不新增红卡奖励。

图鉴展示红卡名称、图标与碎片进度，允许查看详情。未解锁仍需集齐10片手动解锁，不会把首次碎片当作整卡；升星与天赋装备沿用当前系统。

六张旧卡从活动目录、战斗伤害、击杀、充能与控制挂点中退出，只在兼容映射中保留旧ID：玫瑰→火、种子→毒、炉心→炮、重锤→电、霜眼→冰、风灯→回旋。读档合并最高星级与碎片、保留所有权，移除旧键；重复读档不重复迁移。不改动金币、钻石或粉尘。满星红卡碎片沿用现有UR保存规则。

检查：六卡注册表、旧数据幂等迁移、36种地图／卡／碎片掉落结果、非目标战场及早期波次排除、真实击杀奖励入口、结算、猩红宝箱→图鉴→解锁→升星→天赋装备、图鉴UI与旧战斗挂点扫描；保留微信真机验证。

## 掉落提升

所有现有随机掉落入口增加5个百分点：精英碎片5%→10%、小Boss碎片20%→25%、大Boss额外碎片50%→55%；精英宝箱10%→15%、小Boss宝箱50%→55%。大Boss宝箱维持100%上限。通关红卡保底5～10片，地图说明读取同一配置。
