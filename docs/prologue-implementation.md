- 第一章不生成技能候选；直接调用选择接口也不能激活技能。全局技能和战地补给同时在画面入口与实际操作处关闭。

- 每次显示下一组候选都重建当前候选，避免预先生成的队列在前一次选择后失效；跨塔消费与自动选择路径均验证。
