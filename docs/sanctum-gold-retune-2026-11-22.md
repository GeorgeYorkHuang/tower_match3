# 金效果重调：三系列统一 6 格 + 回旋金重设计（2026-11-22）

> 起因：3★ 金"每消除 12 个同色块"触发一次，实战里一轮下来金效果几乎看不到；回旋塔能量长期满仓，「回风归源」返的 4 点能量没有实际价值。
> 结论：**三系列金统一 6 格**；圣庭回旋金整条重做；熔铸炮金因 6 格会永动需下调单次返还。紫效果、名额、闭环不动。

---

| 金 | 原 | 新 |
|---|---|---|
| 圣庭·烬火圣印 | 每 12 红块，灼烧 3 秒 30% | 每 **6** 红块，其余不变 |
| 圣庭·轰鸣核心 | 每 12 橙块，下次普攻免能耗 | 每 **6** 橙块，其余不变 |
| 圣庭·霜心圣晶 | 每 12 蓝块，100 范围减速 30%/3 秒 | 每 **6** 蓝块，其余不变 |
| 圣庭·蚀生之种 | 每 12 绿块，毒素 4 秒 40% | 每 **6** 绿块，其余不变 |
| 圣庭·雷脉棱晶 | 每 12 黄块，麻痹 0.5 秒 | 每 **6** 黄块，并补"短暂减速"文案 |

## 2 六格触发的实现与必须同步的三件事

### 2.1 实现点

`js/talents/runtime.js:52-56` 现在写死 `12`：

```
if (state.charge[key] >= 12) { state.ready[key] = true; state.charge[key] %= 12; }
```

改为按卡的间隔取值（默认 6，留出后续单独调某张的口子）：

- `gain()` 读 `state.goldInterval[key]`（`initialize` 时从卡的 `gold.interval ?? 6` 写入）；
- `ready` 仍是布尔（不叠储备），余数 `%= interval`；
- 卡面/图鉴的"每消除 12 个"文案统一改成 6（含圣庭 6 张的 `gold.desc`）。

### 2.2 翻倍后必须加"dot 条数上限"（否则火/毒会爆炸）

现状 `_talentDots` 是**每次触发 push 一条新 dot，不限制条数**（`runtime.js:97-106`）。12 格时 3 秒内最多并存 1~2 条；改成 6 格后可能并存 3~4 条，dot 伤害直接翻倍还不止。

定：**同目标、同类型（火灼烧 / 毒毒素）最多并存 2 条**，第 3 条进来时替换"剩余时间最短"的那条。

- 上限效果：火灼烧最多 2×30% = 60% 累计，毒毒素最多 2×40% = 80% 累计。
- 为什么是 2 而不是 1：保留"连续触发有收益"的手感，又不至于叠成一条永远不掉的毒柱。

### 2.3 其余四条天然不叠，不用改

| 金 | 叠加方式 | 6 格后的实际变化 |
|---|---|---|
| 炮·免能耗 | 每发独立，无叠加 | 从"偶尔免一发"变成"大部分发都免"，**炮塔 DPS 明显上升**（见 4.2） |
| 冰·减速 | `applySlow` 取强不叠 | 覆盖更稳，强度不变 |
| 电·麻痹 | `Math.max` 取长不叠 | 麻痹几乎常驻，冰紫（对麻痹 +15%）随之常亮 |
| 火/毒 dot | 见 2.2 | 需要上限兜住 |

## 3 回旋金完全重设计：从"回能"改成"全队破风易伤"

### 3.1 为什么不能用"返程额外伤害"

回旋塔本身已经有「折返增伤」（`js/combat/towers/boomerang.js:18-27`：返程命中额外一段 + 折返风眼爆炸），再给一条"返程额外 30%"等于把技能复制一遍，数值还会和技能档位、遗物叠乘，验收时根本分不清哪段是谁的伤害。所以这条必须换一个**塔没有的维度**。

### 3.2 新设计

| 项 | 定稿 |
|---|---|
| 名称 | **回风归源**（名字保留，图标与图鉴 id 不动） |
| 触发 | 每消除 **6** 个紫块，下一发回旋弹**返程首次命中**（沿用 `_talentReturned` 一次判定） |
| 效果 | 给主目标挂「破风」**4 秒**：该目标**受到的所有来源伤害 +10%** |
| 叠加 | 同目标**不叠层**，只刷新时长（否则回旋高频命中会把 10% 挂成 30%） |
| 乘区 | 与熔铸「淬裂」、霜风「风痕」同属护甲后的易伤区，**加算合并** |
| 边界 | Boss 吃；召唤物吃；返程未命中→不消费；技能命中不触发（只认普通回旋弹返程） |
| 卡面 | 「每消除6个紫块，下一发回旋弹返程命中使目标破风4秒，受到伤害 +10%。」 |
| 验收断言 | ① 挂上后火塔打同一目标伤害 +10%；② 4 秒内再挂只刷新，不出现 20%；③ 回旋返程落空时 `ready` 保留 |

### 3.3 为什么是"全队易伤"而不是别的

- 圣庭现有 6 张紫全是"某塔对某状态 +15%"，**没有一张是全队增益**；补一个全队易伤，正好是回旋塔"辅助位"的定位，也让圣庭的金不再全是"自己打自己"。
- 回旋塔射程长、命中多、单发弱——"挂易伤"这种不依赖单发强度的效果，是它最合适的产出方式。
- 名字对得上：「回风归源」＝把风引回来，给别人开路。
- 数值保守：10% 比熔铸淬裂的 8% 略高，但圣庭没有别的易伤来源，且不叠层，常驻上限就是 10%。

### 3.5 实现落点（三处，改动很小）

1. **传目标进去**：`towers/boomerang.js:59` 现在是 `returnHit(combat, s)`，而那一行正好在碰撞到敌人 `e` 的分支里 → 改成 `returnHit(combat, s, e)`。该行外层已有 `ready.boomerang` 判断，不用重复。
2. **`runtime.js:159-166` 的 returnHit**：删掉 `tw.energy += 4`，改成挂状态——

```
function returnHit(combat, shot, e) {
  if (shot._talentReturned) return;
  shot._talentReturned = true;
  const run = combat.game.run;
  if (!consume(run, 'boomerang')) return;
  if (e && e.hp > 0) e._windBreak = statusDuration(run, 'boomerang', 4);
}
```

3. **易伤区合并**（`damage.js:96` 之后）：破风、淬裂、风痕、真火全部加算成一次乘法，不要各自乘一遍——

```
let vuln = 0;
if (e._windBreak > 0) vuln += 0.10;   // 圣庭回旋金
if (e._quenchCrack > 0) vuln += 0.08; // 熔铸冰金
if (e._windMark > 0) vuln += 0.08;    // 霜风回旋金
vuln += 真火(按灼烧层数);
if (vuln > 0) v *= 1 + vuln;
```

4. **状态递减**：`statuses.js` 的 `tickBaseStatus` 里加 `if (e._windBreak > 0) e._windBreak = Math.max(0, e._windBreak - dt)`。

保留 `_talentReturned`（一发只结算一次），不要因为换了效果就把它去掉。

### 3.6 平衡锚点（首版预期）

- 单目标常驻率 = `min(1, 触发次数 × 4 秒 / 战斗时长)`。一局若消除紫块约 400~600 格，按 6 格一次 ≈ 70~100 次触发，几乎全程覆盖。
- 所以这张金的实际价值 ≈ **全队对单目标 +10% 持续增伤**，但要扣掉"目标被换掉时重新挂"的空窗。
- 它不叠层，因此不会像淬裂那样出现"多塔围攻同一目标叠成 30%"的失控；也不会和圣庭紫的 +15% 冲突（紫在护甲前，破风在护甲后，乘算）。

## 4 这次改动对平衡的影响（要重采）

### 4.1 圣庭整体是"上"不是"下"

上一轮"紫名额 1"是削弱，这一轮"金 6 格 + 回旋金增伤"是加强，两股力量方向相反。粗算：

- 火/毒 dot：条数上限 2 条 → 最多 60% / 80% 累计，比原来单条 30%/40% 翻倍；
- 冰/电：控制覆盖翻倍（麻痹几乎常驻 → 冰紫常亮）；
- 炮：免能耗翻倍，炮塔有效 DPS 上升；
- 回旋：从 0 收益变成每 6 格一次全队 +10% 易伤。

**结论：圣坛不能沿用 11-21 的旧数据，也不能只按"紫 1 个"的削弱估。必须重跑一轮，重点看 1★ 臂（紫名额 1 最疼的是低星）。**

### 4.2 炮金是六条里最需要盯的一条

圣坛没有弹药上限压力，炮"免能耗"本身就很强；6 格后近乎永动，可能把炮塔变成唯一解。如果采样显示炮塔占比过高，优先把**炮金单独改回 9 格**（`gold.interval` 已经按卡配置，改一个数字就行），而不是砍免能耗本身。

## 5 三系列统一 6 格（已定）+ 逐张复核

统一 6 后，熔铸/霜风的金会变密。逐条过一遍，**只有熔铸炮返能需要改数值，其余天然不叠**：

| 金 | 6 格后的实际变化 | 处理 |
|---|---|---|
| 圣庭火/毒 dot | 3 秒内可并存 3~4 条 | 加"同目标同类型最多 2 条"（第 2.2 节） |
| 圣庭炮 免能耗 | 近乎永动 | 先按 6 落地测，过强再单独调 9 |
| 圣庭冰/电 | 取强/取长，覆盖更稳 | 不改 |
| 圣庭回旋 | 换成全队易伤 10% | 不叠层，见 3.2 |
| 熔铸火 熔穿 | 3 秒不叠只刷新 → 常驻 | 不改（本来 W10 后也常驻） |
| **熔铸炮 返能** | **6 格 + 击杀返 2 = 永动**（每发扣 1~2，6 格一次返 2） | **击杀返 1、未击杀返 0**（频率翻倍、单次减半，净收益持平） |
| 熔铸冰 淬裂 | 3 秒不叠 → 常驻 | 不改 |
| 熔铸毒 硫毒 | 同目标 1 条、刷新 → 常驻 | 不改 |
| 霜风冰 冻结 | 0.6 秒 + 防冻壳 1 秒，覆盖率约 37.5%，只刷新 | 不改 |
| 霜风火 解冻 | 只在冻结时消费，冻结变多 → 消费变多 | 不改（仍不满足则不消费） |
| 霜风回旋 风痕 | 3 秒不叠 → 常驻 | 不改 |
| 霜风炮 减速 | 取强不叠 | 不改 |

**熔铸炮返能的"返 1"要写进卡面**：「每消除6个橙块，下一次炮塔强化普攻：击杀敌人回 1 能量，未击杀不回能。」

## 6 本轮已闭口的结论

1. 三系列金统一 **6 格**，间隔走 `gold.interval ?? 6`（按卡可调，用于后续单独调炮金）。
2. 熔铸炮金 **击杀返 1**、未击杀不回能、未命中不消费。
3. 圣庭回旋金 = **破风**：返程命中挂 4 秒、全队受到伤害 +10%、不叠层。
4. 圣庭火/毒 dot 加"同目标同类型最多 2 条"。

剩下的都是执行：`gold.interval` 配置化、`returnHit` 改造、易伤区合并、四张卡文案替换。
