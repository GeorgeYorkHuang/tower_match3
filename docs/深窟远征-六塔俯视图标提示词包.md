# 深窟远征 · 六塔俯视图标提示词包 v1

> 交付人：游戏美术师　日期：2026-10-28　状态：**提示词待评审，确认后先出 2 张基准图**
> 上游文档：`docs/消消防线-美术风格提案.md`（风格锚点 v1 / 色彩板 / 后处理链）
> 本文件只解决一件事：**把六座塔画成「从正上方俯瞰」的图标**，并保证 98px 槽内六塔可辨。

---

## 0. 结论先行

1. 俯视图标不是"把侧视图转个角度"，它的辨识度**只能靠轮廓与同心结构**——因为塔身高度被压掉了。
2. 因此本方案给六塔各定一个**俯视轮廓母题**（圆瓣 / 六角 / 三管 / 八角十字 / 风车 / 单管），做到**灰度也能区分**，不依赖颜色。
3. 视角取 **82° 近顶视**，不是 90° 正交顶视：留 8° 倾角才能看到外壁一圈厚度与装置投影，否则塔会塌成"井盖/徽章"。这是本方案与"纯顶视"唯一的偏离，也是最关键的一处。

---

## 1. 视角方案：为什么是 82°，不是 90° 也不是 45°

| 方案 | 结果 | 判断 |
|---|---|---|
| 90° 正交顶视（纯俯瞰） | 只看得到塔顶平面，无厚度、无高度、无投影 → 像徽章、像地面图案，四塔并排像四块地砖 | ✗ 不可用 |
| 82° 近顶视（**本方案**） | 塔顶装置占 90% 画面，外壁露出约 1/10 的一圈厚度，投影短促贴底 → 既"从上往下看"，又立得住 | ✓ |
| 45° 俯视（战场环境用的角度） | 高度可见，但四塔并排互相产生"朝向错觉"，且与"俯瞰"诉求不符 | ✗ 偏离需求 |
| 等距 isometric（30°） | AI 最容易漂到的默认姿势，体积感强但与竖版正面战场冲突 | ✗ 明确禁用 |

**提示词里的硬写法**（防漂三件套，缺一必漂）：

```
orthographic top-down view, camera pitched 82 degrees from horizontal,
very high angle looking almost straight down, only a thin rim of the outer
wall visible, no horizon, no sky, no ground plane, tight contact shadow
directly under the base offset slightly to bottom-right, no long cast shadow
```

**负面词必须写死**（俯视图最常漂成这几个）：

```
isometric, 45 degree view, side view, three-quarter view, horizon line,
perspective vanishing point, flat icon on ground, manhole cover, badge, emblem
```

## 2. 六塔俯视轮廓母题（本方案的核心）

> 设计原则：**先看轮廓能否区分，再看颜色**。每座塔的俯视外形都由三层构成——**基座（地基）→ 机构（机能）→ 顶装置（识别符号）**。

| 塔 | 主色（冻结） | 俯视**轮廓母题** | 三层结构 | 灰度辨识点 |
|---|---|---|---|---|
| **火塔** | `#ff6b6b` | **圆 + 放射瓣** | 八块石砌基座环 + 深色炉膛口 + 三瓣火焰喷口 | 圆盘中三个尖瓣 |
| **冰塔** | `#5dade2` | **六边形 + 尖晶** | 六边冰岩台 + 霜裂纹 + 中心六出冰棱簇 | 唯一六边形，且中心有**立起的尖** |
| **毒塔** | `#58d68d` | **圆 + 三根外伸管** | 圆石台 + 中央坩埚液面 + 三根 120° 等角斜管 | 唯一有**三向伸出物** |
| **电塔** | `#f4d03f` | **八角 + 十字四叉** | 八角石台 + 三层同心铜线圈 + 四根避雷叉 | 唯一八角 + 同心圆环 |
| **回旋镖塔** | `#af7ac5` | **环 + 四旋臂（风车）** | 金属导轨环 + 四枚 V 形刃切向排列 + 中心轴 | 唯一"环状中空" |
| **炮塔** | `#e67e22` | **圆盘 + 单一炮管** | 厚装甲炮座 + 后座液压杆 + 一根短粗炮管朝 12 点 | 唯一**非对称、有明确朝向** |

**六塔之间的差异矩阵**（任两塔至少差 2 项，避免同屏混淆）：

```
对称性：炮塔非对称 / 其余五塔轴对称
外轮廓：冰塔六边 · 电塔八角 · 其余四塔圆形
中心：火塔花瓣 · 冰塔尖晶 · 毒塔液面 · 电塔线圈 · 回旋塔中空 · 炮塔炮口
伸出物：毒塔三管（120°）· 电塔四叉（90°）· 回旋塔四臂（切向）· 炮塔一管（唯一单向）
```

## 3. 提示词包（四段式，与风格提案同构）

### A 段 · 锚点段（俯视专用，逐字复用，一处不改）

```
2D flat cartoon game asset, casual fantasy dungeon theme, ORTHOGRAPHIC TOP-DOWN
VIEW pitched 82 degrees, looking almost straight down at the tower top, only a
thin rim of the outer wall visible, no horizon and no sky, top-left key light
with subtle warm gold ambient rim light, matte flat colors with light painterly
texture, no glossy reflections, unified 6px dark-purple-black outline #0E0B14,
chunky rounded stylized proportions, high-saturation gem palette on deep
purple-black background #17121f, crisp clean edges, readable silhouette,
WeChat mini-game casual tower-defense art style
```

> 与风格提案 A 段的唯一差异：`3/4 front view` → `ORTHOGRAPHIC TOP-DOWN VIEW pitched 82 degrees`，并补 `no horizon and no sky`。其余逐字一致，保证与怪物/UI 图标同一世界。

### B 段 · 主体槽位表（六塔，一次只换这一行）

| 槽位 | 取值 |
|---|---|
| {塔} | 见 §4 六条完整 prompt 的第二段 |
| {尺寸} | 1024×1024 生成 → 512×512 交付，单主体居中占 82%（留 9% 安全边给升星光环与槽位描边） |
| {背景} | 纯洋红 `#FF00FF`，无渐变、无投影（供 keyout 抠图） |
| {朝向} | 炮塔炮管朝画面正上方（12 点）；其余五塔轴对称，不受朝向影响 |
| {状态} | 常态（升星态后续用"外圈光环 1/2/3 道"叠加，不重画主体） |

### C 段 · 质量与负面词（逐字复用）

```
positive: centered composition, three clearly separated layers with visible
height, unmistakably a built stone-and-metal structure not a gem or a flat
emblem, clear silhouette readable when scaled to 98 pixels, game-ready asset

negative: isometric, 45 degree view, side view, three-quarter view, horizon line,
perspective vanishing point, flat ground icon, manhole cover, badge, emblem, coin,
gem, jewelry, realistic masonry photo texture, pixel art, blurry, complex
background, text, numbers, watermark, logo, thin sketch lines, long cast shadow,
soft gradient glow, multiple towers, split view, character, creature
```

## 5. 验收标准（每张必过，不合格不进入下一张）

| # | 检查 | 通过标准 | 不合格处理 |
|---|---|---|---|
| 1 | **98px 缩略** | 缩到 98×98（游戏内 `towerIcon.size`）仍能认出是哪座塔 | 加粗中心装置、去掉细节 |
| 2 | **灰度测试** | 转灰度后六塔两两可区分 | 改轮廓母题，不放宽 |
| 3 | **三层可读** | 基座 / 机构 / 顶装置 三层分离清楚，不糊成一坨 | 提高层级明度差 |
| 4 | **建筑感** | 一眼是石头+金属造的塔，不是宝石/徽章/井盖 | 加铆钉、铁箍、砖缝 |
| 5 | **视角一致** | 六张的外壁厚度、投影方向、光照方向完全一致 | 重跑，勿肉眼容忍 |
| 6 | **色彩冻结** | 主色等于 `TOWER_HEX` 对应值，无二次调色 | 直接改提示词色号重跑 |
| 7 | **同屏测试** | 六张排成接触表，与现有暗金 UI 面板叠一张 | 谁抢眼谁降饱和 |

## 6. 生成纪律与下一步

1. **先 2 张，不 6 张**：先出 **火塔**（轴对称代表）+ **炮塔**（非对称代表）。这两张能验证"俯视是否立得住"与"轮廓差异化是否有效"，是全部六塔的胜负手。
2. 两张过 §5 全部 7 项检查 + 你点头 → 冻结视角与线宽 → 再放量冰/毒/电/回旋四张。
3. 每轮迭代 `_v1 → _v2`，旧版保留，只改你指出的那一项。
4. 六塔定稿后，同一套俯视语言可延伸给：塔位槽底纹、塔详情页大图、图鉴卡片封面——**一次定锚，三处复用**。

### 待你确认（2 件）

1. **视角**：82° 近顶视（能看到一点外壁厚度与高度）是否可接受？如果你要的是**纯粹 90° 正顶视**（完全看不到侧壁，更"地图符号"感），我把倾角改到 90 并加厚中心装置，但六塔会明显更"平"。
2. **轮廓母题**：六个外形（圆瓣/六角/三管/八角十字/风车/单管）是否认可？尤其**毒塔的三根外伸管**与**回旋镖塔的中空环**——这两项外观最"怪"，但正是它们让六塔在灰度下不混。
