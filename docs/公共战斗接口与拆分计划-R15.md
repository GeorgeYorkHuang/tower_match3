# R15 公共战斗接口与拆分计划

## 本批基准与边界

基准a5e7d69，已包含W的技能配置三项调整。本批只改combat兼容入口，新增combat/targeting.js与测试，不改main、render、touch、配置、圣遗物效果或资源。没有新派工。

## 依赖矩阵

| 能力 | 当前入口 | 读取/写入 | 迁移边界 |
|---|---|---|---|
| 目标与范围 | range/towerMuzzle/pickTarget/pickAltTarget/inTowerRange | 读TOWERS、combat-common、场景布局、slotOrder与Enemy hp/坐标；额外目标用Math.random | 本批已提取，返回原Enemy对象，不排序/复制敌人数组 |
| 弹道登记与基础命中 | addProjectile/resolveShot/stepShot | 写shots、fx和shot时间/完成标记；调用hit、damage和onHit | 下一批先几何/通用终点命中，再逐步迁stepShot；保留回调和visual双向引用 |
| 弹道几何 | scatterCheck/sweepPos | 散射更新shot._collisionP，读Enemy坐标；回旋轨迹仅计算位置 | 低依赖，可先迁；命中时消失、不穿透、多弹道互不取消 |
| 带塔行为的弹道 | stepShot的orb/bounce、sweepDamage | 电球随机转向/麻痹、电痕；弹力镖反弹/分裂；回程圣遗物、风痕 | 与电/镖塔强耦合，不能当纯几何一起搬；每类弹道单独验 |
| 伤害结算 | shotDmg/damage/explode | 读塔DPS、能量、商店、圣遗物乘区与协同；写Enemy hp、来源、击杀计数；可递归onKill | 单一伤害入口，不复制公式；P2/P3另立项；记录先伤害后状态及递归顺序 |
| 状态与DoT | tickStatus/applyBurn/applyPoison/applyBleed/applySlow/freezeE | 读塔分支与圣遗物；写Enemy dots、控制/计时/层数；触发damage/explode | 先基础状态工具，再按状态类型；毒/火叠层、伤害快照和死亡回调原样 |
| 持续区域/召唤物 | updateGroundDots/updatePoisonSticks/updateMines/updateTurrets/updateStorms/updateWindTrails | 实体列表属于当前Combat；同时依赖塔、状态、伤害与fx | 随对应塔逐批迁，不能只按循环外形合并 |
| 塔行为 | attackOnce/hit*/tick*与子方法 | 依赖目标、弹道、伤害、状态、能耗与配置；写塔实例冷却和分支计数 | 先明确上下文，再一塔一批，首塔火或冰视公共接口准备情况决定 |
| 主调度/清理 | update/reset/tickPeriodic | 决定时间窗口、弹道、状态、召唤物、普攻、周期技与尸体统计顺序 | 最后迁，不提前重排阶段；全歼/撤离统计不漏不重 |

统一使用显式combat上下文，每次调用读取当前Run/Enemy；无模块级玩家状态。共享配置只读；实例的hp/能量/冷却/弹道/持续区不可写回定义。首批不设计一个囊括全部方法的公共大对象，按实际依赖逐步收紧接口。

## 第一批实际交付

`combat/targeting.js`导出五个函数，签名为原参数前增加combat：range(combat,key)、towerMuzzle(combat,key)、pickTarget(combat,key)、pickAltTarget(combat,key,main)、inTowerRange(combat,key,x,y)。Combat同名方法保留委托，所有现有调用点无需修改。

保留以下历史行为：

- 塔口随slotOrder和布局计算；未知/未入槽key按原逻辑回落首槽；测试场固定(65,1103)。
- 射程仍为max(60, 配置range−50)，按调用时配置读取。
- 普攻按直线距离取最近活怪，射程边界包含；同距时优先敌人数组靠前者。
- 额外目标在主目标上方40px（参数取combat-common）水平带与直线射程内随机取；无候选返回原主目标且不调用随机数。
- inTowerRange仅按纵向距离判断，与普攻不相同；修正了旧注释的“同口径”误导，未改行为。

## 验证

`tools/_test_combat_targeting.cjs`使用固定a5e7d69完整旧Combat实现：540组主目标组合、108组额外目标组合。覆盖六塔、正常/测试场、三种布局、槽位正反/空、死怪/无怪、射程与水平带边界、候选顺序、RNG次数及原对象身份；验证输入不变、两个实例隔离和配置修改后读取同源。

多弹道与延迟弹道、焰雨3★、圣遗物击杀1370组、波次554组、撤离检查点11项均通过。

现有wx触摸测试17通过/1失败：仍要求已下架的chain配置弹窗存在，属W界面新规格对应的旧用例，尚待同步。本批没有把这项记为通过。美术资源工作区改动未纳入本提交，也未验证其完整性。
