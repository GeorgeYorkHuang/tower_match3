# R15第十一批：毒塔行为拆分

## 接口与所有权

新增`js/combat/towers/poison.js`，五个入口显式接收Combat，保留原有兼容入口：

- hitPoison：先判定叠毒，再结算普攻直伤。
- tryAttackDebuff：原统一debuff中poison分支，保留剧毒/毒牙与概率触顶行为。
- tickEnemyStatus：瘟疫传染、毒藤缠绕叠毒、瘴气区域/减攻/周期叠毒与小爆炸。
- tickPoison：毒池、毒棒、毒藤周期施放与实体生成。
- updatePoisonSticks：毒棒寿命、独立攻击、附加毒层/减速和消失留毒池。

Combat.tickStatus继续先调用Statuses.tickBaseStatus，再委托PoisonTower.tickEnemyStatus，控制/DoT/传染先后顺序不变。所有层数、敌人计时、召唤物、地面、塔能量归当前实例，无模块级状态；仅共享tower-skills定义。

applyPoison/poisonStack仍走公共状态工具；updateGroundDots仍为跨塔共享区域推进；毒爆/毒藤死亡扩散及圣遗物死亡效果仍按Combat.onKill/RelicKill原协调，不在本轮重排。

## 保持原行为

- 毒池/毒棒周期到点无目标时return会退出整段tickPoison，不改成continue或继续后续技能。
- 毒池DPS为施放快照；毒棒直伤为召唤快照，附加毒层仍读取当前shotDmg；毒巢消失毒池也按消失时值读取。
- 瘟疫减速、概率与范围、速疫全目标/单目标随机选择顺序不变；毒藤定身/叠毒及瘴气四次小爆炸门槛不变。
- 毒棒先扣ttl，过期先留地面再删除，不攻击；按y最大敌人优先。大dt不补跳或补召唤。
- 瘴气未激活时继续按原逻辑清对应fx，不把公共状态/其他特效清掉。
- 不改isSkill、毒层公式、经验/充能/掉落、P2/P3或已确认的连消设计。

额外断言验证先叠毒后直伤、空场毒池施放退出后续技能、毒棒直伤快照/附毒当前值、毒巢2秒地面与双Combat隔离。
