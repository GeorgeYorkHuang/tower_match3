## 1. 一页结论

| 项 | 现状 | 本稿 |
|---|---|---|
| 战场与 Boss | 每 5 波一只「血更厚的同款」 | **3 场 ×（20 波小 Boss + 40 波小 Boss + 60 波终极 Boss）= 9 只**，每只绑定本场规则 |
| 波次上限 | `WAVE.maxWave = 9999`（无尽） | **60**，波 60 为终极 Boss 战 |
| Boss 波形态 | 与常规波同构：40s 计时，边刷怪边打 | **锁关 Boss 战**：进度暂停、不刷后续波、Boss 死才进下一波 |
| 阶段结构 | 无阶段（少数只有一次性变形） | 小 Boss **2P**（1→2 技能）、终极 **3P**（1→2→3 技能） |
| 阶段刷怪 | 无 | **每个 P 进入时追加 1 波**，数量 P1→P2→P3 逐级 +20%~+25% |
| Boss 血量 | 主代 ×32（终极 84,800） | **按目标时长反推**：小 Boss 60s / 终极 110s（§3），终极约 **111.6 万** |
| 单个 Boss 战时长 | 3–8s（数值上等同 1/10 波） | **小 Boss 54–60s、终极 100–110s**，三阶段可完整呈现 |
| 代际 / 41–60 波 | 40+ 走拍平公式，波 50 总血反比波 45 低 25% | Lv9–Lv14 手工表 + 逐波递替表，压力单调（§6） |
| 圣遗物掉率 | 权重全局统一（金 12%），Boss 与精英无差异 | Boss 阶梯金率（20% / 26% / 40%）+ 6 件**战场专属红**（§16） |

**核心判断**：锁关之后，Boss 战不再是「波次里的一只厚怪」，而是一段独立演出——它的长度由玩家 DPS 与阶段血阈共同决定，而不是由 40 秒波计时决定。这带来两个必须同步的口径变化：① Boss 血量要按战斗时长反推（否则阶段走不完）；② 波次总血量的结算口径要改（否则深度与排行失真，§12-6）。

## 2. Boss 战流程（本次新增的核心规则）

### 2.1 锁关：进入 Boss 波即暂停关卡进度

| 时点 | 行为 |
|---|---|
| 进入波 20 / 40 / 60 | `run.bossLock = true`：**不启动常规 40s 波计时、不排下一波刷怪队列**；本波只生成 Boss + 阶段追加波 |
| Boss 战期间 | 波数冻结（HUD 只显示「BOSS」与阶段名），深度记账暂停，波间商店不开启 |
| Boss 死亡 | 立即结算本波（掉落、银币、深度 +1）→ 解除锁关 → **进入下一波**，计时与刷怪恢复 |
| 城墙破防 | 走既有失败 / 复活流程；**复活后回到本 Boss 波，Boss 血量保留现场值**（不重置，避免重复刷阶段奖励；§14-6） |
| 主动撤离 | Boss 战中允许撤离，深度按「已完成的上一波」计，Boss 波不计 |

> 设计意图：Boss 战是「一段」，不是「一波」。玩家在 Boss 战里的时间只花在打 Boss 与清追加波上，不会被下一波小怪同时挤压。

### 2.2 阶段推进

- 阶段由**血量阈值**触发，各触发一次、不重复：小 Boss `100–50% / <50%`；终极 Boss `100–70% / 70–35% / <35%`（霜风因分裂机制拆点，见 §9.3）。
- 每次进入新阶段：**① 解锁 1 个新技能（旧技能保留、累计生效）；② 立即追加 1 波小怪；③ 血条上出现阶段刻度与阶段名。**
- 切换有 0.5s 硬直 + 全屏演出（震屏 / 光效 / 顶部提示），给玩家明确的「该换打法了」信号。

### 2.3 技能累计表（硬约束）

| Boss | P1 | P2 | P3 |
|---|---|---|---|
| 小 Boss（20 波） | S1 | S1 + S2 | — |
| 小 Boss（40 波） | S1 | S1 + S2（含裂生与共鸣） | — |
| 终极 Boss（60 波） | S1 | S1 + S2 | S1 + S2 + S3 |

> 与 v2 的差别：v2 的三阶段是「三套互斥打法」，本稿改为**累加**——终极 Boss 到 P3 时同时在召唤、加护盾、打真伤，压力曲线自然上翘，不需要额外的数值放大器。

## 3. 数值口径重算（旧值作废）

### 3.1 反推公式

```
有效 DPS 基准   d = 本波总血 / 40s × 0.8（清场率）
目标时长        T = 小 Boss 60s / 终极 Boss 110s
Boss 波总伤害   D = 本波总血 × T / 40 × 0.8
Boss 有效血量   E = D − Σ追加波血量
Boss 名义血量   H = E × (1 − 护甲)
```

据此 `K = T×0.8/40`：小 Boss **1.2**、终极 **2.2**。**K 的含义是「这一战相当于几波小怪的血量」**——比「主代 ×32」好懂，也好调。

| 波 | 本波总血 | DPS 基准 | 目标时长 | 总伤害 D | 追加波合计 | Boss 有效血 E |
|---|---|---|---|---|---|---|
| 20 | 118,200 | 2,364/s | 60s | 141,840 | 8,800 | 133,040 |
| 40 | 555,560 | 11,111/s | 60s | 666,672 | 50,320 | 616,352 |
| 60 | 846,000 | 16,920/s | 110s | 1,861,200 | 145,020 | 1,716,180 |

| Boss | v2 旧值 | v3 新值 | 倍差 | 原因 |

### 3.5 推进与撞墙（软计时器）

既有代码移速换算为「`1.5` 基准单位 = 40s 走完全程」，即 `到达城墙时间 ≈ 60s / spd`：

| Boss | 移速 | 到达城墙 | 目标时长 | 结论 |
|---|---|---|---|---|
| 小 Boss 20（圣坛/熔岩） | 0.75 / 0.70 | 80s / 86s | 60s | 晚 20–26s → 天然的「输出不足」惩罚 |
| 小 Boss 20（霜风） | 0.95 | 63s | 57s | 只差 6s → 本场容错最低 |
| 小 Boss 40 | 0.74 / 0.70 / 0.96 | 81s / 86s / 63s | 60s | 同上 |
| 终极 Boss | 1.05 / 0.95 / 1.55 | 114s / 126s / 77s | 100–110s | **必须停步**：霜风 77s 会在 P3 前撞墙 |

- **小 Boss 保持推进**：到达时间（63–86s）比目标时长晚 6–26s，正好当软计时器（撞墙 198/252 一次，10/8 次破防）。
- **终极 Boss 推进到路径 80% 的「对峙位」即停步**，之后只用技能（真伤 / 腐蚀 / 召唤 / 冰封）施压——城墙压力来自技能与漏怪，而不是普攻。

## 4. 战场绑定原则

1. **机制引用规则**：每只 Boss 至少有一条技能直接放大该战场既有规则（`ammoCapMult` / `windEvery` / 基准场无减益）。
2. **视觉语言同源**：Boss 形象与出场特效必须一眼归到战场（藤蔓与石像 / 矿渣与熔炉 / 冰壳与霜风）。
3. **反制资源对应**：最优解落在该场 `dropAttr` 的掉落取向上（圣坛 mix / 熔岩 attack / 霜风 control）。

| 战场 | 战场规则（代码事实） | Boss 如何引用 | 该场 Boss 考什么 |
|---|---|---|---|
| **圣坛花园** `ancient` | 基准场：`ammoCapMult 1.0`、无减益、`dropAttr mix` | 藤蔓结壳、石像双生、圣母庇护与裂坛爆发 | 清场优先级、爆发窗口、别被拖成消耗战 |
| **熔岩矿场** `lava` | `ammoCapMult 0.7`（弹药 −30%）、高血精英、`dropAttr attack` | 攻速压制（过热 / 矿渣骤冷）逼「存弹药、等窗口」；护甲更高、血条更短 | 弹药管理、窗口输出、读条打断 |
| **霜风峡谷** `frost` | `windEvery 15`（每 15 波风场增速）、高速成群、`dropAttr control` | 冰甲疾行、双啸分裂、冰封控塔；血条最长、护甲最低 | 控场覆盖、AoE、冗余布塔 |

## 5. 追加刷怪配方（按强度递增）

### 5.1 强度基准

- 每波追加怪总血 ≈ **Boss 有效血的 4%–7%**：形成「必须分心清场」的压力，又不盖过 Boss 本体。
- 阶段内递增：终极 P2 比 P1 多 20%、P3 比 P2 多 17%；小 Boss 的 P2 比 P1 多 25%。
- 代际取本波同代（20 波用 Lv6/Lv5，40 波用 Lv9/Lv10，60 波用 Lv13/Lv14），不引入跨代怪。
- 出场：阶段切换后 **5 秒内分批涌出**（不是瞬间同屏），从两侧入口进入。
- 战场倾向：熔岩偏重坦（高血厚甲）、霜风偏快速（低血高速）、圣坛均衡。

## 6. 波次结构与代际（承自原稿，数值未改）

### 6.1 补 6 代怪物（Lv9–Lv14）

代际入口沿用「每 5 波进一代、新旧按比例混合」的既有节奏：Lv9@34、Lv10@39、Lv11@44、Lv12@49、Lv13@54、Lv14@59。

## 15. 验收口径

**锁关与流程**

1. 进入波 20/40/60 后：`wave` 不递增、无常规刷怪、40s 计时暂停；Boss 死亡后 `wave+1` 且计时恢复。
2. Boss 战期间深度不记账；撤离按上一波结算。
3. 破防复活后回到同一 Boss 波，Boss 血量等于死亡前数值。

**阶段**

4. 小 Boss 恰好在 50% 触发 1 次 P2；终极 Boss 恰好在 70% / 35% 各触发 1 次，不重复、不跳过。
5. 每次进 P 时：技能数 +1（累计生效）、追加波数量与 §5 表一致、出场在 5s 内完成。
6. 终极 Boss 到路径 80% 停步，停步后不再推进。

**数值**

7. 木桩实测单场时长：小 Boss 54–66s、终极 100–120s（±15% 容差）。
8. 有效 DPS 基准复核：本波总血/40s×0.8 与实际清场速度偏差 <20%，否则回调节点。

**战场绑定**

9. 不串场：波 20/40/60 的 Boss `id` 必须匹配当前 `field`；三场各跑一遍，`Set(bossIds).size === 9`（深渊复用圣坛 3 只，共 12 次调用）。
10. 规则引用自检：每只 Boss 至少一条技能字段指向该场规则键（`ammo` / `wind` / `base`），否则数据校验失败。

**机制与结算**

11. 结壳型：3 层上限、每层吸收 5% 名义血、破壳后护甲 0 且移速/攻速按表变化。
12. 分裂型：<60% 分裂 2 只各 30%；共鸣 10s/+12%/3 层；8s 双杀追加白银；超时独存回血 15%。
13. 免疫：冻结/击退对终极 Boss 无效；小 Boss 控制时长 ×0.5。
14. 掉落：波 20 白银、波 40 裂痕、波 60 星辉 + 裂痕，均只发一次。
15. 回归：其余波次（5/10/15/25/30/35/45/50/55）常规 Boss 数值与行为不变；`test` 战场不受影响。

## 16. 圣遗物掉落体系（Boss 驱动 · 红色战场专属）

### 16.1 现状盘点（三个必须先说清的事实）

| # | 代码事实 | 影响 |
|---|---|---|
| 1 | 稀有度只有 `r / sr / ssr` 三档（`RELIC_RARITY`），碎片权重全局一套 `{r .60, sr .32, ssr .08}`（`KILL_DROP.rarityWeight`），三选一权重 `{r .50, sr .38, ssr .12}`（`RELIC_PICK_WEIGHT`） | 没有「红色」这一档，也没有任何 Boss 专属掉落 |
| 2 | Boss 掉落的宝箱与精英掉落走**同一个三选一**（`main.js` `spawnRelicPick`），权重不区分来源 | 「Boss 提升金色概率」目前完全不成立，打 Boss 与打精英的手感一样 |
| 3 | Boss 已额外掉碎片（`bossShardBase 4 + 50% 加 2`），但碎片按 `field.dropAttr` 从全池随机 | 掉落与战场无关，「刷哪个场」对收藏没有指向性 |

### 16.2 新增稀有度：红（`ur`）

- 代码键 `ur`，中文名「**红 · 专属**」，卡面红金描边（`#e8402f` 底 + `#ffd166` 内发光），图鉴单独分区「战场专属」。
- **不入任何随机池**：`randomShardCardId` / `randomShardId` / 三选一池均不含 `ur`，只能由该战场 Boss 掉落（这是「专属」的技术保证）。
- 升星：`STAR_UP.ur = { 2: { shards: 20, stone: 2 }, 3: { shards: 50, stone: 5 } }`；重复获得折算 `DUPLICATE_SHARDS.ur = 10`。
- 三档效果沿用现有 `desc / star2 / star3` 文案结构，效果挂点复用现有 `relic3(id)` 判定，不新增触发器类型。

### 16.3 掉落矩阵（按来源分级，金率逐级提升）

口径说明：金/红都按**整箱**判定（先 roll 一次），紫/蓝按**每张卡**判定——这样「单箱最多 1 金」是规则自带的，不靠事后降级打补丁。

**A. 整箱金率（本箱至少 1 张金）**

| 来源 | 现在 | 本稿 |
|---|---|---|
| 精英宝箱（三选一） | 12% | **12%**（不变） |
| 普通 Boss（5/10/15/25/30/35/45/50/55） | 12% | **20%** |
| 小 Boss 20 波 | 12% | **26%** |
| 小 Boss 40 波 | 12% | **26%** |
| **关底 Boss 60 波** | 12% | **40%** |

**B. 未出金时，其余 3 张卡的稀有度**：紫 **70%** / 蓝 **30%**（每张独立；金箱里另外 2 张也走这条）。

**C. 专属红（整件，独立于三选一）**

| 来源 | 概率 |
|---|---|
| 小 Boss 20 波 | **25%** |
| 小 Boss 40 波 | **40%** |
| 关底 Boss 60 波 | **100%** |

**三条配套规则**

1. **单箱最多 1 金**：金是箱级 roll，天然只有 1 张；不会出现「3 张全金」把实际收益翻 3 倍。
2. **红不进三选一**：红色整件**直接入账**并播放专属演出（红光扫屏 + 卡面飞入 + 图鉴红点），不占候选位、不可重掷。
3. **红立即入账**：不参与现有碎片「局末入账 / 失守 30% 折算」流程——Boss 已经打死了，奖励不该因为后面失守被扣。

### 16.4 保底与防重复

| 规则 | 内容 |
|---|---|
| 关底首通 | 首次击杀该场关底 Boss → **必掉未拥有的那件**；两件都已有 → 随机一件 + 重复折算红碎片 ×10 |
| 单局上限 | 同一件红色单局最多掉 1 次（三档 Boss 共用一张「本局已掉」表） |
| 小 Boss | 只掉**本场 2 件中随机 1 件**，不区分 20/40 档的池子，只区分概率（25% / 40%） |
| 失守 | 已入账的红色不回收；红碎片按现有 30% 折算 |
| 图鉴 | 未拥有的红卡在图鉴显示轮廓 + 「掉落：<战场名> 20/40/60 波」，可点「前往」跳回主页并切到该场 |
| 深渊裂隙 | Boss 复用圣坛组 → **红池也复用圣坛 2 件**（同概率，诅咒乘算不影响掉率）；没有自己的专属红 |
| 测试战场 | 无任何圣遗物掉落（`dropAttr === 'none'` 时整条掉落线短路） |

### 16.8 验收口径（圣遗物）

1. **不入池**：把 `randomShardCardId` / `randomShardId` / 三选一池各跑 10,000 次，`ur` 出现次数为 0。
2. **金率阶梯**：普通 Boss / 小 Boss / 关底各模拟 10,000 次三选一，箱级金率 ≈ 12% / 20% / 26% / 40%（±2%），且**单箱金卡数 ≤1**。
3. **小 Boss 红率**：20 波 25%、40 波 40%（±2%）；同一件单局不重复掉。
4. **关底保底**：两件都未拥有时首次通关必掉未拥有；已全拥有时转红碎片 ×10 并提示。
5. **专属隔离**：圣坛 Boss 不掉熔岩/霜风红，反之亦然（三场各 500 次断言）。
6. **入账时机**：红色整件立即写入 `meta`，失守后仍在；红碎片仍按 30% 折算。
7. **升星**：2★ 消耗 20 碎片 + 2 星辉石、3★ 消耗 50 + 5；碎片不足时按钮置灰并提示差额。
8. **弹窗**：点击战场图标弹出（不再只 toast）；点遮罩/关闭键均关闭；未解锁战场显示蒙层且不拦截「查看」；测试战场走无掉落文案；`menuPanel` 打开时不能穿透点到「进入战斗」。
9. **图鉴**：6 件红卡在「战场专属」分区可见，未拥有显示轮廓与掉落来源，「前往」能切到对应战场并回到主页。

### 16.9 待拍板（圣遗物）

| # | 议题 | 选项 | 建议 |
|---|---|---|---|
| 1 | 红件形式 | 整件直掉 / 红碎片合成 | **整件直掉**：Boss 掉落的仪式感强，也不需要再造一套碎片 UI |
| 2 | 小 Boss 红率（25% / 40%） | 保持 / 下调（15/30）/ 上调（35/50） | **保持**：60 波通关才是主门槛，小 Boss 只是「提前摸到」的甜头 |
| 3 | 关底是否 100% 必掉 | 100% / 70% + 保底计数 | **100%**：60 波一局成本高，必掉才值得打 |
| 4 | 金率阶梯（20/26/40，箱级） | 保持 / 更保守（15/18/25） | **保持**：普通 Boss 从 12%→20%（1.7×）、关底 40%（3.3×），但金只是「3 张候选里 1 张」，且老玩家多数金已解锁，实际是「升级材料加速」而非「白送新卡」 |
| 5 | 红色强度（是否允许「无视护甲」这类硬解） | 允许 / 只做数值加成 | **允许**（裂坛玫瑰 3★、碎渣重锤 3★）：红的定位就是「解某个战场最难受的一层」，纯数值红没有存在感 |
| 6 | 弹窗入口 | 点图标 / 长按图标 / 图标旁加「掉落」按钮 | **点图标**：现有 `stage` 命中区本来空着，零新增占位；徽标负责提示可点 |
