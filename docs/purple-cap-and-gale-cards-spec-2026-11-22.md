## 1 紫卡名额规则（新增）

### 1.1 配置

```
SERIES_PURPLE_CAP = { sanctum: 1, forge: 2, gale: 2 }
```

- 圣庭 1：老战场只有 1 个紫生效，压住旧强度，也和老玩家"已经堆满紫"的既有体验拉开差距。
- 熔铸/霜风 2：这两个战场全局效果更难（熔壳/风压），紫给 2 个是**补偿**，不是加码。
- 数值放 `js/config/red-series.js`（跟着系列走），不要写死在 `model.js`。

### 1.1b 一套 6 个圣物里，不是每张都有紫、也不是每张都有金

先把现状说清（2026-11-22 用 `model.js` 的 `footprint` 实算了 18 张卡在各自槽位的结果）：

| 星 | 4 格 / 8 格 / 12 格 | 覆盖自己紫点 | 能出紫 | 能出金 |
|---|---|---|---|---|
| 1★ | 4 格 | **N**（全部 18 张都不覆盖） | 否 | 否 |
| 2★ | 8 格 | Y（全部 18 张都覆盖） | 是 | 否 |
| 3★ | 12 格 | Y | 是 | 是 |

也就是说现在 18 张卡的天赋档位**结构完全一样**（2★紫、3★紫+金），是程序化派生出来的"整齐"。这不是想要的：6 个圣物应该有的"2★ 就有收益"、有的"必须 3★ 才值"，名额竞争才有意义。

**每系列的档位分布（2026-11-22 已修正为 4/2/0 与 2/2/2，详见 `purple-slots-and-series-tiers-2026-11-22.md`）**：

| 系列 | 双（紫+金） | 只紫（无金） | 只金（无紫） |
|---|---|---|---|
| 圣庭 | 6 张已上线，**不动** | — | — |
| 熔铸 | 4 张：火、炮、冰、毒 | 2 张：**电、回旋** | **0 张** |
| 霜风 | 2 张：冰、火 | 2 张：**毒、电** | 2 张：**回旋、炮** |

分配理由：

- 熔铸：熔穿（火金）、淬裂（冰金）、硫毒（毒金）、返能（炮金）是四条主链，必须保留；电金（熔流分叉）、回旋金（碎渣返程）砍掉，这两张全靠紫做纯增伤件（电电力吃熔穿，回旋吃护甲 ≥15%）。
- 霜风：风痕（回旋金）、冻结（冰金）、解冻（火金）是枢纽；炮金是减速来源，保留；毒金只补伤害，砍掉后毒靠"减速 ≥25% +12%"；电只紫 → 没有麻痹来源，电紫条件从"麻痹中"改为"带风痕"。
- 只紫卡在 3★ 的收益＝覆盖 8→12 格（多 4 个绿白），**卡面必须写"3★：仅扩大覆盖，无金效果"**，否则玩家以为升 3★ 有隐藏效果。
- 只金卡在 2★ 的收益＝只有覆盖，紫金都不亮，**装配面板要标"2★ 无效果，建议 3★"**，并把"2★ 即有收益"的卡排在前面。

**工程表达不用新增字段**：只紫 = `gold.enabled=false`；只金 = `purple.enabled=false`。`model.js:64/66` 已经在按这两个开关过滤，直接置 false 即可。

结果：熔铸紫池 6 张（名额 2/6）、金池 4 张；霜风紫池 4 张（名额 2/4）、金池 4 张。局内最多 4 塔，金不会挤。

### 1.2 名额怎么分配（唯一口径）

1. 参选集合 = 已装配 + 该卡**有紫**（`purple.enabled !== false`）+ `star ≥ 2` + 该卡紫点被任一红卡覆盖（沿用 `model.js:63-65` 现有判定）。
2. **按 `nativeSlot` 升序（0→5）取前 CAP 张**，其余进入"待命"（`purpleBench`）。
3. **该塔本局没建也照样占名额，不递补**。这是有意的：`initialize` 在开局调用，那时还没有塔，如果按"局内实际塔"分配，结果会随建塔顺序、拆塔重建抖动。固定"槽位序号靠前优先"才能保证同一套装配在任何一局结果一致。
4. `star` 掉回 1★ 或卸下卡 → 名额空出，后面的卡按序递补。
5. 拆塔/重建**不影响**名额分配（只看装配与槽位）。

### 1.3 玩家怎么看得到

| 位置 | 显示 |
|---|---|
| 天赋盘预览（装配时） | 每张本系列卡标「紫·生效」/「紫·名额已满（由 炽核 占用）」；顶部一行 `紫 1/1`、`紫 2/2` |
| 卡详情页 | 紫效果下面加一行：「本系列紫槽 2/2，超出不生效」 |
| 战斗 HUD | 本系列紫名额小标签 `紫 2/2`，只在装配了 ≥3 张本系列卡时出现（避免常驻噪音） |
| 首次被顶掉 | 一条 toast：「熔铸紫槽已满：炽核、膛压生效，其余紫效果不参与战斗」 |

> 必须做到"装配时就知道结果"。否则玩家进局才发现第 3 张紫白装，这是最容易挨骂的点。

### 1.4 叠加与乘区

1. **同系列多紫同时满足条件 → 加算合并为一次乘法**：`1 + Σ`（两个 12% = 1.24，不是 1.2544）。
2. **同条件同数值不重复计入**：所以紫条件必须差异化，否则第二张等于白给（下面重做就是为这件事）。
3. 紫仍沿用现有位置：`beforeDamage`（护甲**之前**）——**本轮不改这个位置**。理由：改到护甲之后会把圣庭紫的实际收益从"W60 熔岩 ≈6.9%"变成 15%，等于全盘重调，且和本轮目标无关。
4. 因此存在两个加算组，互不合并：
   - **A 组（护甲前，`beforeDamage`）**：圣庭紫、熔铸紫、霜风紫
   - **B 组（护甲后，易伤区）**：淬裂 +8%、风痕冰电 +8%、真火灼烧层
   - A 与 B 之间是乘算（1.24 × 1.08 ≈ 1.339），误差 <1%，可接受。

## 2 熔铸紫（6 张全有紫；电、回旋无金）

设计原则：熔铸的压力是"护甲 + 弹药 −30%"，紫就全部围绕这两件事，且每张盯一个不同信号，让"2 个名额"变成真正的组合题。

| 卡 | 紫名 | 条件（本塔造成伤害时判定） | 加成 |
|---|---|---|---|
| 熔铸·炽核熔炉（火） | 熔渣灼甲 | 目标**有效护甲 ≥30%**（含熔壳，不含熔穿） | 火塔直接伤害 +12% |
| 熔铸·膛压炉心（炮） | 膛压贯甲 | **本塔当前弹药 ≤ 上限 40%** | 炮塔全部伤害 +12% |
| 熔铸·淬火槽（冰） | 冷淬崩甲 | 目标**处于减速状态**（任意来源，强度 ≥20%） | 冰塔伤害 +12% |
| 熔铸·硫磺脉（毒） | 硫脉蚀甲 | 目标**身上有任一 dot**（含毒自身） | 毒塔伤害 +12% |
| 熔铸·电弧熔渣（电） | 熔渣导弧 | 目标**带熔穿** | 电塔伤害 +12% |
| 熔铸·矿渣回旋（回旋） | 矿渣旋切 | 目标**有效护甲 ≥15%**（含熔壳，不含熔穿） | 回旋塔伤害 +12% |

> 电、回旋是只紫卡（`gold.enabled=false`），3★ 只扩覆盖；其余 4 张双。见 1.1b。

**组合强弱（供平衡侧关注）**

- 最强组合：**火紫 + 冰紫**。冰塔自带减速 → 冰紫自己满足自己；火挂熔穿 + 火紫吃 ≥30% 护甲。两条件几乎常驻，等于稳定 +24%。
- 次强：**电紫 + 火紫**。全靠火塔挂熔穿，一旦火塔等级低/没建，电紫就空转。
- 最弱：**炮紫 + 毒紫**。都依赖自身资源或状态，属于"补短板"组合，不是增伤组合。
- 设计上接受这个梯度，但平衡采样必须至少覆盖"火+冰"这一组，它是熔铸的上限样本。

> 对比上一版：6 张里有 5 张是「对熔穿 +15%」，2 个名额等于玩家只能挑 1 张真正有用的，另一张纯凑数。本版每张条件独立，装哪两张会明显改变打法。

## 3 霜风紫（4 张：冰、火、毒、电；回旋、炮只金）

霜风的压力是"移速被风压抬 + 减速时长被削"，所以紫必须奖励"把控制铺满"这件事。

| 卡 | 紫名 | 条件 | 加成 |
|---|---|---|---|
| 霜风·凝霜之心（冰） | 霜心凝滞 | 目标**处于冻结中** | 冰塔伤害 +12% |
| 霜风·融霜火线（火） | 融霜余烬 | 目标**处于解冻后 2 秒窗口**（`_thawTtl > 0`，见 5.2） | 火塔伤害 +12% |
| 霜风·霜蚀孢子（毒） | 霜蚀渗透 | 目标**处于减速状态**（任意来源，强度 ≥25%） | 毒塔伤害 +12% |
| 霜风·静电风眼（电） | 静电风眼 | 目标**带风痕**（电只紫无麻痹来源，故条件改为风痕） | 电塔伤害 +12% |

> 回旋（逆风回响）、炮（霜炮轰鸣）是只金卡（`purple.enabled=false`），2★ 无紫无金、只有覆盖，卡面/面板要标"2★ 无效果，建议 3★"。
> 6 张里 2 双（冰、火）+ 2 只紫（毒、电）+ 2 只金（回旋、炮），见 1.1b。

**设计意图**

- 冰紫（冻结）、回旋紫（风痕）、电紫（麻痹）三条都是"自己铺、自己吃"，属于可自洽的控制链。
- 毒紫要求减速 ≥25%，注意风压只削**时长**不削**强度**，所以强度门槛不会被风压破坏。
- 火紫是唯一"别人铺、自己吃"的：靠冰塔冻结后再解冻，专门奖励"冻→火"的节奏。这条必须配 `_thawTtl`（2 秒增伤窗口），和 `_thawImmune`（1 秒不可再冻）是两个独立计时器。
- 炮紫靠"群聚"，风压让敌人走得慢 → 更容易聚 → 这是风压给玩家的正反馈。
- 最强组合：**冰紫 + 火紫**（冻住 → 冰紫吃 → 火塔解冻 → 火紫吃，且解冻本身 2 倍伤害），是霜风的"标准答案"，平衡采样必须覆盖。
- 最弱组合：**毒紫 + 电紫**（都要别人先把减速/麻痹铺上，自己启动不了）。

## 4 霜风 6 张金（定稿，工程验收级）

沿用熔铸定稿的框架：触发 / 数值 / 叠加 / 边界 / 验收。

### 4.1 霜风·凝霜之心（ice · 槽 4）

| 项 | 定稿 |
|---|---|
| 金名 | **霜心领域** |
| 触发 | 每消除 12 个蓝块，下一次冰塔普攻命中；命中即消费 |
| 效果 | 以主目标为中心 **90 范围**内所有敌人：减速 **35% / 3 秒**；其中**带风痕**的目标额外 **冻结 0.6 秒** |
| 叠加 | 减速取强不叠加；冻结不叠时长，取 `max` |
| 边界 | ① 减速**强度**不被风压改，**时长**吃风压削减（满 5 层 −40% → 约 1.8 秒），这是风压的代价；② 冻结 0.6 秒受 `_thawImmune` 阻挡（免疫期内只上减速）；③ Boss 冻结按 `bossDurationRatio` 缩短；④ 范围内无风痕目标 → 只有减速，仍消费 |
| 验收断言 | ① W60（风压 5 层）实测减速时长 ≈1.8 秒而非 3 秒；② 目标刚被解冻（`_thawImmune>0`）→ 本次不冻，但减速照上；③ 一次命中 3 只，3 只都减速 |

### 4.2 霜风·逆风回响（boomerang · 槽 2）

| 项 | 定稿 |
|---|---|
| 金名 | **逆风刻痕** |
| 触发 | 每消除 12 个紫块，下一发回旋弹**返程**命中主目标时 |
| 效果 | 给主目标挂「风痕」**3 秒**：该目标受到的**冰、电伤害 +8%** |
| 叠加 | 同目标不叠层，只刷新；与「淬裂」加算合并（1 + 0.08 + 0.08） |
| 边界 | Boss 吃；不吃控制抗性；返程未命中不消费；碎渣类衍生伤害不挂风痕 |
| 验收断言 | ① 挂上后冰塔伤害 +8%；② 淬裂+风痕同时存在 → 合计 16%；③ 3 秒内再次上痕只刷新时长 |

### 4.3 霜风·静电风眼（electric · 槽 3）—— 只紫卡，无金

| 项 | 定稿 |
|---|---|
| 金名 | **无**（`gold.enabled=false`）；3★ 仅扩大覆盖 |
| 紫（2★） | **静电风眼**：电塔对**带风痕**的敌人 +12%（风痕由回旋金提供） |
| 卡面文案 | 3★「覆盖12格：4绿、1紫、7白；仅扩大覆盖，无金效果。」 |
| 验收断言 | ① 2★ 时对带风痕目标 +12%；② 3★ 面板无金效果、无"设计中"字样 |

> 原「风眼雷涌」（连锁 2 名 100 范围 50% + 麻痹 0.4 秒）随"电只紫"作废。连锁 AOE 由霜风炮金与电紫本体承担；麻痹机制在霜风里不再存在，因此电紫条件改为风痕，不依赖麻痹。

### 4.4 霜风·霜蚀孢子（poison · 槽 5）—— 只紫卡，无金

本卡 `gold.enabled = false`。紫「霜蚀渗透」= 对处于减速状态（强度 ≥25%）的敌人 +12%。3★ 只把覆盖从 8 格扩到 12 格，卡面需写明「3★：仅扩大覆盖，无金效果」。

> 门槛为什么按"减速强度"而不是"有效移速比例"：满 5 层风压下敌人移速 ×1.47，冰金减速 35% 后实际仍 ≈0.96 原速，按"移速 ≤75%"判的话后期永远不满足，条件等于废掉。按强度判则不受风压干扰。

> 说明：原本设计的「霜蚀 dot（10%/秒、减速中 +1 秒）」随金效果一起砍掉。理由是霜风的金要留给体系枢纽（风痕、冻结、解冻、减速），毒金只是补伤害；砍掉后"减速铺满"的回报由紫承担，也顺带简化了一条 dot 叠加规则。

### 4.5 霜风·融霜火线（fire · 槽 0）

| 项 | 定稿 |
|---|---|
| 金名 | **融霜爆裂** |
| 触发 | 每消除 12 个红块，下一次火塔普攻命中；**仅当目标处于冻结时消费**，未冻结不消费（机会保留） |
| 效果 | ① 该次伤害 **×2**；② 立即解冻（`e.frozen = 0`）；③ 设 `_thawImmune = 1.0`；④ 设 `_thawTtl = 2.0`（火紫增伤窗口）；⑤ 叠 **1 层**灼烧 |
| 叠加 | 灼烧沿用现有点燃 stack 上限；`_thawImmune` 取 `max` |
| 边界 | Boss 吃 2 倍与解冻；召唤物同样；目标同时被多次冻 → 只解一次；未冻结则整条不触发、不消费 |
| 验收断言 | ① 冻结目标挨这一发伤害翻倍且立刻解冻；② 之后 1 秒内冰塔再冻不上；③ 2 秒内火塔后续普攻吃到火紫 +12%；④ 目标没冻结时空放，ready 不变 |

### 4.5 霜风·霜炮轰鸣（cannon · 槽 1）—— 只金卡，无紫

| 项 | 定稿 |
|---|---|
| 金名 | **霜炮轰鸣** |
| 触发 | 每消除 12 个橙块，下一次炮塔普攻（爆炸命中） |
| 效果 | 爆炸范围内所有敌人减速 **30% / 2 秒**；若爆炸主目标**带风痕** → 减速半径 **×1.3（130）** |

## 5 三个新增/复用的状态标记

| 标记 | 用途 | 时长 | 谁设置 | 谁读 |
|---|---|---|---|---|
| `_thawImmune` | 防"解冻即再冻"循环，期间**不可被冻结** | 1.0 秒 | 融霜爆裂解冻时 | `freezeE` 入口 return + `tickBaseStatus` 每帧压 `frozen=0` |
| `_thawTtl` | 火紫「解冻后 2 秒」增伤窗口 | 2.0 秒 | 同上（解冻瞬间） | 火紫条件判定 |
| `_windMark` | 风痕：受冰/电伤害 +8% | 3.0 秒 | 逆风刻痕、冰金（若带） | 冰/电伤害的易伤区 |

`_thawImmune` 豁免范围维持已定稿：**只挡冻结**，不挡减速、麻痹、定身、眩晕。

## 6 这一轮对平衡的影响（必须先说清）

1. **圣庭整体削弱**：从"装几张紫就吃几张 15%"变成"只吃 1 张 15%"。按旧报的圣坛数据（C1 1★ 83%、C3 3★ 100%），这条落地后 1★ 臂会明显下滑，3★ 影响小（金卡不受限）。**结论：圣坛基线必须重采，旧 11-21 数据不能直接对新版本用。**
2. **熔铸/霜风变强**：紫从 15% 提到最多 24%，但条件是"状态型"，需要玩家自己铺。首版手感大概率是"新手觉得没变化、老手觉得 +9%"。
3. **不要给圣庭加补偿**（不建议把 15% 提到 18%）：圣坛是入门战场，1 紫 15% 正好；补偿会让三系列的差异重新糊掉。若实测 1★ 通关率掉到 60% 以下，再考虑把圣庭紫移到护甲后（收益变大）而不是加数值。
