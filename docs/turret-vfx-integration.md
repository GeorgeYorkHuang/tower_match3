# 召唤炮台待机与开火表现

已确认示例的游戏接入，仅替换炮塔技能召唤的小炮台。

- 参考：pixelfx `projectiles/cannonball`，改编炮口闪光、烟雾与弹丸；炮台本体为单独绘制。保留 MIT LICENSE、NOTICE。
- 导出：透明 PNG，20 FPS，单帧 224×128，锚点 (60,112)；待机 48 帧循环 2.4 秒，开火 17 帧、0.8 秒。
- 图集：`assets/images/towers/fx/turret-v2/`。运行时使用 CommonJS 裁帧表，不依赖 JSON 模块加载。
- 参数：`js/config/turret-vfx.js`。当前显示倍率 1.15；最后 0.35 秒淡出。开火播放时长取 0.8 秒与攻击间隔×0.85 的较小值，确保最快攻击间隔下可以完成后坐复位。
- 每门炮台绑定独立表现对象；由实际攻击触发，战斗时间推进。暂停不消耗表现寿命；倍速同步；消失和重开清理。
- 原目标选择、伤害、溅射、能量返还保持原逻辑。旧炮口闪光和火星由新图集替换，保留命中连线。
- 图片未加载时使用固定底座与后坐炮管绘制兜底。

验证包含实际召唤与攻击、同位置多炮台独立状态、无目标、寿命结束、暂停、倍速、重开、裁帧、左右镜像和加载失败。真机视觉表现仍需在微信小游戏中查看。
