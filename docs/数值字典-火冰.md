## 0 读前必读：四个单位约定

| # | 约定 | 为什么容易错 |
|---|---|---|
| 1 | **伤害系数乘的是「单发普攻伤害」**（`shotDmg()` 的返回值），不是面板 DPS | 火塔 `atkInterval=0.9s`、冰塔 `1.1s`，`shotDmg = 面板DPS × 间隔`。把 0.44 当成「面板 DPS 的 44%」会算错约 10%~40% |
| 2 | **半径/宽度/偏移 = 逻辑像素**（750×1626 设计稿） | 真机 375pt 宽时为显示值的一半 |
| 3 | **时间是秒**；**概率/百分比是 0~1 小数** | 配置里 `0.30` 意为 30%，不是 30 |
| 4 | **分支档位数组 `[0, x1, x2, x3]`**，下标 = 该分支等级（0 = 未点），档位之间**不累加**，取当前等级那一个值 | 写 `(1 + arr[lv])` 的字段是「加算百分比」；写 `arr[lv]` 的是「绝对值」——两种都有，见每张表的「用法」列 |

## 1 乘区总图（两段式）

伤害进 `damage()` 之前只经过两条路，**先算技能系数，再乘塔的全局乘区**，顺序固定：

```
① 面板 DPS（三消等级成长 × 塔基础 32/20 …）
   × atkInterval                      ← 折成「单发伤害」= shotDmg 的输出
② shotDmg(key, isSkill) 内 7 个乘区（combat.js:187，顺序即代码顺序）
   1 × 全局锻造           gsState.forge > 0 → ×1.25          （config/global-balance.js）
   2 × 局内商店攻击强化   (1 + 0.2 × 层数)                   ← 本局临时
   3 × 圣遗物伤害%        (1 + rl/100)  rl = 力量符 + 塔遗物 + 4连叠层 + 城墙背水
   4 × 全局充能3★技能伤   (1 + chargeSkillBoost/100)  ← **仅 isSkill=true 时生效**
   5 × 洗牌增益           _shuffleBuffTtl > 0 → ×1.3
   6 × 能量耗尽弱化       能量 ≤ 0 → ×0.5                     （CONFIG.GLOBAL_SKILL.weakDmg）
   7 × 周期弱化           period × 1.5（只影响周期技释放间隔，不改伤害）
③ 技能基础系数            本文各表的「基础值」列（迁移后基本都走 `SKILL_NUM.*` 配置）
④ 分支倍率                本文各表的「档位」列，每技能只乘其中一个分支的档位
⑤ 爆炸附加乘区            explode() 内（C3346）：协同[1]（重炮×大火球）达成 → ×1.5  ← 见 §3-P3
```

**自检口诀**：一个技能的最终伤害 = `shotDmg × 技能系数 × (1 + 分支档位)`。表里只要出现第四个乘法项，就是特例，会在「说明」列标出来。

**为什么值得提**：冰花（8s 周期）、冬珠（10s 周期）与火柱（10s 周期）是同一类「周期技」，火柱吃技能伤、冰花/冬珠不吃；同一件圣遗物对同类技能效果不一致，玩家侧表现为「充能3★只强化火系周期技」。
**复现步骤**：
1. 存档给 `chargeSkillBoost = 100`（或带满级全局充能3★）
2. 同面板下分别施放火柱与冰花，记录单次伤害
3. 火柱伤害约为无加成时的 2 倍，冰花不变
**连带影响**：`碎冰`（不吃）与 `冰冻 C 碎冰`（吃）名字相近但口径不同，调参时极易误判。

### P3 `explode()` 的 1.5 协同加成不判塔别 🟡

`explode()`（C3342）内部 C3346：`if (synergyDone[1]) mult *= 1.5`，**不判断 `key`**。
协同[1] 名为「重炮×大火球」，但只要达成，火系所有走 `explode()` 的伤害一并 +50%：

| 受影响路径 | 读取位置 |
|---|---|
| 火柱爆发 | `tickFire` C2040 `explode(wv…)` |
| 火雨 燃尽加速3★ 附爆 | `tickFire` C2191 |
| 爆燃 击杀爆炸 | `onKill` C1035 |
| 灼烧 B 燃尽 满层爆 | `applyBurn` C1999 |
| 冰冻 C 碎冰 | `onKill` C1113（冰系也吃） |

**复现步骤**：达成重炮×大火球协同后，只放火柱（不放炮塔攻击），对比协同前后火柱单次伤害 → +50%。

### S2 不走 `shotDmg` 的伤害（不在塔乘区里）🟢

| 伤害 | 公式 | 读取位置 |
|---|---|---|
| 冰墙 B 霜反 | `吸收量 × reflect` | `siegeEnemies` M532 |
