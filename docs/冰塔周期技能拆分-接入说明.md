# R15第八批：冰塔周期技能拆分

新增IceTower.tickIce(combat,dt)，Combat.tickIce保留兼容委托。冰花、冬珠、冰墙与冰晶/冰雾地面、冰墙裂变返能均迁到combat/towers/ice.js。实体/计时属于当前Combat/Run，不缓存或回写配置。

## 保留边界

- 冰花仍登记到公共delayed队列，0.8秒后回调，伤害/半径为施放快照；回调按原代码引用目标对象当前坐标，未改成完全固定落点。
- 冰晶与雪崩回调照原顺序追加地面/2秒与4秒延迟队列，倍率0.8/0.64不变。
- 冬珠保存施放时伤害，按原ttl/tick顺序推进；过期先移除，大dt不新增补跳；冬域减速转冻及冷却保持原样。
- 冰墙先推进旧盾、到期回血/碎裂冻结，再判新盾施放；吸收/反伤字段及主流程攻城结算不迁移。
- 地面和墙伤返能仍在tickIce末尾，返能封顶、伤害余数保留。技能关闭时原有门控行为不改。
- 不修改isSkill口径、伤害乘区、周期/耗能、P2/P3或UI。
