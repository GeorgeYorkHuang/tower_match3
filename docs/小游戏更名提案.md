# 小游戏更名提案 v1（待定稿）

> 交付人：游戏美术师　日期：2026-10-28　状态：候选名提案，未动任何代码/文案
> 现名：**消消防线**（三消 × 塔防 × Roguelike，微信小游戏）

---

## 0. 结论先行

1. 现名最大问题：**「消消」连读被听成「消防」**——第一印象变成消防游戏，玩法（三消）和题材（地下深窟）一个都没传达；且与「消消乐」家族名称惯性冲突，搜索时被大厂产品淹没。
2. 推荐首选：**「深窟消消塔」**（玩法直白型）——三消、塔防、地窟三词全占，ASO 搜索词全覆盖，连读无歧义。
3. 推荐备选：**「宝石深窟」**（题材氛围型，适合走品质感路线）与 **「撤离！深窟」**（卖点型，把独有的撤离机制放进名字）。
4. 定名前必须做：微信公众平台名称查重（小游戏名全网唯一）+ 商标近似检索（重点避开「消消乐」类注册商标）。

## 1. 命名标准（本项目专用）

| 标准 | 要求 |
|---|---|
| 长度 | 3–6 字，微信分享卡片与图标下标题不截断 |
| 玩法传达 | 含「消」「塔」「宝石」至少一个 |
| 题材传达 | 含「深窟 / 深渊 / 地窟」类地下意象（与四战场世界观一致） |
| 连读安全 | 任何两字连读不产生歧义词（消防/小数/消失等） |
| 商标安全 | 不含「消消乐」「XX乐」等已注册高频词根 |
| 搜索友好 | 玩家搜「三消」「塔防」「消消」至少能命中一个词根 |

## 2. 候选名（12 个，分三型）

### A 玩法直白型（ASO 最强，推荐主力）

| 候选 | 连读检查 | 优点 | 缺点 |
|---|---|---|---|
| **深窟消消塔** ⭐ | 无歧义 | 消/塔/窟三词全占；词序把题材放最前，有画面感 | 5 字略长 |
| 消消深窟 | 无歧义 | 消消开头符合品类搜索习惯 | 「消消」仍是泛用词根，识别度靠后两字 |
| 宝石消消塔 | 无歧义 | 「宝石」直指三消盘面主题 | 未传达地下题材 |
| 三消守城记 | 无歧义 | 「守城」比塔防更口语 | 丢了「深入」的 roguelike 感 |

### B 题材氛围型（品质感路线）

| 候选 | 连读检查 | 优点 | 缺点 |
|---|---|---|---|
| **宝石深窟** ⭐ | 无歧义 | 4 字干净；与宝石盘面、四战场（熔岩/霜风/废墟/深渊矿窟）世界观严丝合缝 | 玩法需靠副标题/图标补 |
| 深窟远征 | 无歧义 | Roguelike 远征感强 | 完全不含玩法词 |
| 方块深渊 | 无歧义 | 「方块」暗示三消 | 「方块」略生硬 |
| 熔窟之下 | 无歧义 | 氛围最强 | 太文艺，小游戏场景不占优 |

### C 卖点型（把机制放进名字）

| 候选 | 连读检查 | 优点 | 缺点 |
|---|---|---|---|
| **撤离！深窟** ⭐ | 无歧义 | 「撤离」是全游戏最独特的机制记忆点，带动词有紧迫感 | 感叹号部分平台名不支持，需备选写法「撤离深窟」 |
| 越深越险 | 无歧义 | 直说难度超车的核心体验 | 0 玩法词，纯口号 |
| 深度撤离 | 无歧义 | 双关「深度收益池」 | 像 B 站术语，游戏感弱 |
| 下潜吧防线 | 「下潜吧」连读尚可 | 有行动号召 | 略拗口 |

## 3. 推荐组合拳

- **主名**：深窟消消塔（或宝石深窟，二选一定调性）
- **副标题**（商店页/图标角标可用）：「三消供弹 · 塔防守线 · 撤离拿奖」
- **分享卡片文案**：「我下到第 32 波，带着满包宝石撤离了——你敢再深一层吗？」
