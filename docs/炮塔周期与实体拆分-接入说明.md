# 炮塔周期与实体拆分接入说明

R15第十三批，固定旧实现基线1ce9fe7。

## 接入与边界

`js/combat/towers/cannon.js`新增tickCannon(combat,dt)、updateMines(combat,dt)、updateTurrets(combat,dt)。原Combat同名方法保留并委托，更新顺序、调试技能施放和现有调用点保持不变。模块只读取tower-skills配置，计时、地雷、炮台、弹道、特效和延迟队列均留在调用方实例，无共享运行时状态。

炮火支援保留逐发落地延迟与施放伤害快照；公共updateDelayed继续处理实际落点、空袭追加和焦土。地雷保留飞行、落地后0.3秒布设、寿命、到期爆炸、雷场共鸣与碎片闭包。炮台保留存活数量加成、最靠墙目标、施放时伤害快照和到期返能封顶。碎片的伤害与表现继续通过公共Combat接口。

## 保留的历史口径

炮火支援/埋雷/炮台的shotDmg仍按原方式调用，碎片调用shotDmg(cannon,true)，不混入P2修正。炮台直伤后仍执行原爆炸，不添加主目标排除参数。地雷飞行逻辑500px/s与表现时长计算200px/s的既有差异保留；落地时仍设置原20秒寿命。焦土/火线仍使用fire来源。以上均属后续行为或数值任务，不在机械迁移中修改。
