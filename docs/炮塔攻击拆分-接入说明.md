# 炮塔命中拆分接入说明

R15第十二批，固定基线c308d0c。只移动命中主体，入口仍为CombatSystem.hitCannon(e,dmg)，内部委托CannonTower.hitCannon(combat,e,dmg)。

## 边界与数据所有权

模块只读取tower-skills配置并操作调用方的Combat、塔和敌人实例，无模块级可变状态。热度_heat、暴击层_ovCrit仍属于当前塔；火线groundDots仍属于当前Combat。伤害、爆炸、状态与特效通过原Combat接口调用，保留先主弹、后溅射、后贯穿的顺序和随机数消耗。军火之王、点燃与伤害数字沿用公共链路；火线使用fire来源的历史口径保留。

普攻发射调度、双管齐射、tickCannon与地雷/炮台尚在原处，下一批继续迁移。本批不处理P2/P3平衡调整，不实现W的60波/小Boss设计文档。

## 自动验证

运行node tools/_test_cannon_attacks_split.cjs。旧实现从git show c308d0c:js/combat.js加载，不与当前委托自比。3072组组合覆盖技能集、分支档位、圣遗物档位、满/空能量、热度临界、致死与非致死、协同开关及固定随机种子，每组连续命中三次。使用真实damage/explode，记录伤害数字、击杀、状态与特效，并比较随机数调用数。另有主目标不重复溅射、热度清零、贯穿衰减下限与双实例隔离断言。

相关公共伤害882组、弹道456组、毒塔880组及真实Main反馈、Run连消、多弹道替换回归全部通过。

## 用户真机抽查

由用户测试：炮塔普通命中与周围溅射；震击的击退/减速；贯穿多怪及棕色伤害数字；火药3星过热与火线持续伤害。真机结果尚未登记，本批不上传小程序、不推送远端。
