# 连消全格弹道：设计草案 v1

目标：连消中的消除格可见地化为对应颜色攻击弹道，提升棋盘与战场的反馈联系。

## 已确认

新机制替换现有连消额外攻击，正常经验与充能继续；同一格不能同时发旧攻击和新攻击。当前代码第4组起判连消，仅对shape=3匹配组生成弹道，未涵盖四/五消及爆炸波及格。新范围需以该步实际清除格为准。

## 实施方向

1. 从每级消除前快照采集格坐标、原颜色、类型与来源；匹配/特殊爆炸交集按step+row+col去重。同一位置在后续另一消除步出现新格可以再次发射。
2. 用该步清除集合生成弹道描述，不直接读取已清空/下落后的最终棋盘。彩虹自身无颜色和未出战颜色需显式处理，不能默认为红塔。
3. 在对应消除动画阶段发射，避免Run.trySwap提前同步结算全部step时所有弹道同时飞出。一次发射只在真正命中时结算，不在消除和命中各扣一次。
4. 延续公共弹道与伤害入口；发奖仍走原死亡钩子；基础消除的经验、充能、特殊块生成各执行一次。
5. 退出战斗/重开清队列，暂停与三选一不能积压后重复播放；大规模爆炸的视觉预算不能静默丢真实伤害。

## 待实施前明确的细节

- 是否保持现行第4组阈值（建议第一版保持，不夹带改门槛）。
- 无出战塔颜色是否沿用原充能回退；若要求每格均有真实攻击，需单独定义通用来源和伤害基数。
- 每格倍率与是否沿用当前spawnChainShots完整普攻效果。原实现可触发大火球/电连锁等，不是只有基础伤害；全清除格推广会提高出伤，需记录基准DPS和高连消峰值。
- 彩虹无色格和特殊块自身是否发通用表现弹，不能未经确认任选塔色。

以上属于待定设计细节，不阻塞W的纯数据去重/表现模块；依赖这些决策的真实伤害接线暂不实施。

## 验收

三连/四消/五消/爆炸及其交集每格至多一次；颜色从消除前快照正确继承；旧新连消攻击不叠加；经验与充能不变；多级消除按动画级次发射；主目标死亡不取消其他弹道；无敌人/暂停/退出/重开不重复奖励；密集连消在用户设备上核验性能与可读性。

W负责方案、独立清除格/弹道描述模块与预览，Codex负责Run/动画/Combat接线。此文不代表功能已完成。
